# 剪辑库语义路由协议

## 商品、UGC与品牌

- 实物商品演示、真实使用体验、购买问题与品牌叙事走`raven-commerce-story`，先辨别分析/脚本/成片/修改。UGC视觉风格不证明真实顾客经历；素材不足不伪造体验。
- 指定文字与成片窗口的字幕覆盖用`caption-coverage-check`；“这个主张是否有依据/限定是否足够”属于复杂判断。字幕校验不等于ASR/最终音频或OCR验收。
- 软件录屏教学走`raven-software-tutorial`；参数齐全的烧录/音频处理走对应原子。现有作品修改保留当前场景与版本；仅明确价格字段可用局部修改，涉及卖点/风格判断继续商品复杂层。

这是 Agent 的语义分派规则，不是按关键词保证正确率的分类器。读取 `skills.json` 的 Skill 声明，并按[通用能力交接](../contracts/capability-handoff.md)核当前 Agent 的真实工具；本库某个本地实现缺失，不等于其他编辑器工具不可用。规划中的能力可以识别，但当前工具均无对应能力时须返回 `capability-unavailable`，不能被当成已执行。

## 路由结果

记录原始 Query、当前作品/选区、目标、交付模式、场景、主要 Skill、必需原子依赖、约束、解析来源（原话/上下文/推断）、缺项和执行范围。只记录决策及理由，不输出内部推理过程。

1. 明确字段/对象的参数操作直接去原子层，例如“这个片段降 3dB”。对象不明确且上下文不能定位时才询问。
2. 含重要性、自然、情绪、风格、故事、适合等取舍时，由复杂层处理；不能将“最精彩”映射为最大音量。
3. 多操作但参数齐全可以是原子操作队列；一句模糊请求也可以是复杂任务。
4. 判断目标交付：分析、方案、可编辑计划/工程、最终文件或修改。仅分析不得启动生成和渲染。
5. REVISION 延续当前作品和场景，保留手动修改，先确认当前版本而非新建作品。
6. 否定与冻结约束优先解析：“别剧透”“字幕以外都别动”“后面时间位置别变”必须进 TaskSpec。
7. “字幕”需要分辨识别、校对、源到输出映射、样式、烧录；不能以现有 caption-map 冒充 ASR。
8. “配音/音乐”需要分辨生成、选择、摆放、混音。audio-mix 仅消费已有音频，不会生成新声音。
9. “高清/电影感/高级”没有唯一参数，不自动套滤镜或超分；归入需要判断的任务，并结合参考或试做。
10. “导出”检查目标是可编辑工程还是视频；JSON/MP4 不得冒充剪映/Resolve/ChatCut 原生工程。
11. 混合请求保留一份作品和一份计划，用依赖图连接；遇到必需能力缺失，先完成独立部分，明确尚缺阶段。
12. 生成模型、服务选择、凭据和费用由运行 Agent 处理。Skill 只声明需要何种候选素材与回接条件；没有实际候选时不能把计划写成已经生成。

## 当前入口与相邻歧义

- 原创或授权改编的剧情、短剧、漫剧、分章节叙事：`raven-drama-production`（W17）。先定 ANALYZE / PLAN / PRODUCE / EDITABLE / REVISION；只要剧本/分镜即完成相应文本交付，不启动媒体任务。既有作品保持原身份与手改。已有影片的原声剧情剪辑或纯解说仍走 `raven-film-recap`；单镜补足走 `raven-script-generation` 并复用局部修订。六类示例见[剧情路由](../workflows/raven-drama-production/references/route-and-reuse.md)。

- 影视、电视剧或当前作品已为剧情解说：`raven-film-recap`，可按模式只理解、选段、规划或修改。
- 文件哈希/规格：`media-inspect`；指定时间截图：`frame-extract`；指定区间提音轨：`audio-extract`。
- 参数齐全的拼剪：`timeline-render`；明确入出点/增益/恒定片段速度更新：`timeline-patch`。本库 `timeline-render` 接受显式 `speed` 0.5–2（省略为 1），例如已指定片段 0.5 倍慢放可走该参数路径；实际有效源窗内有可消费的非 1× 原声时，默认 `rubberband-r3-stream-v5` 依赖未分发、固定身份的 `rubberband-offline-f32-stream-v5` helper，本源码预览不能直接运行该默认路径，缺失或身份不符时不自动回退。显式支持 `audio_backend.kind="ffmpeg-atempo"`（不接 helper，不继承严格音频证据）和历史兼容 `audio_backend.kind="rubberband-r3-v4"`（有声变速须提供原固定版本、通过身份校验的可执行 helper，源音频时钟须为 `SAMPLE_RESOLVING`，DSP 输入为 48kHz mono/stereo f32，保留 256MiB 整段输入上限）；后端前提与证据边界见[音频后端合同](../contracts/operation-contract.md#默认与显式本地音频后端开发态)。1× 与无声路径按各自合同执行，输出声画仍须验收。速度曲线、光流补帧、跟踪式慢放只在当前 Agent 实查到对应工具后路由，不把恒速能力冒充这些效果。
- 已有源字幕随剪辑映射：`caption-map`；成片时间字幕烧录：`caption-burn`。
- 明确音轨与时间/音量摆放：`audio-mix`；明确规格技术检查：`media-qc`。
- 明确使用本地 macOS 系统语音、音色与速度的合成：`tts-macos`。需要情绪表演或已指定其他 Provider 时不可自动改用该提供方。
- 已有口播/知识讲解的语义剪辑：`raven-speech-edit`，可用已绑定逐词稿调用 `transcript-import` 与 `speech-plan-compile`；可用已核验本地环境中的speech-transcribe-local产生模型观察；未接入的Provider及不可靠时间不能伪装可用。
- 软件录屏剪辑、教程、排错和功能演示：`raven-software-tutorial`；已有素材可编译和渲染，但不包含浏览器录制实现。缺录屏时可先交方案/拍摄单，不能宣称全链路完成。
- 明确源像素矩形与显示窗口：`screen-focus`；“放大重要部分”需要教程复杂层判断目标，不直接按中心裁切处理。
- 明确步骤证据窗口和依赖：`tutorial-plan-compile`；这不是自动识别 UI 操作或自动判断教程完整性。
- 已有作品的局部语义反馈、候选局部采用和范围受限的恢复：`raven-local-revision`，继承场景风格并读取当前作品；只有同一轮继续影视/口播/软件制作且场景入口已加载时，也可由该入口沿用同一作品合同完成，不能创建第二份权威状态。
- 明确候选/修改范围的比较：`timeline-revise`；作品读取、提交、保护声明与恢复：`work-version`；导出：`work-render`。用实际编辑器的项目历史/API 或本库 Work 皆可满足这些能力，保持同一作品、版本冲突拒绝及局部保持。`host-bridge`、`work-delivery` 是选择本地 runtime 后的可选操作，不要求编辑器工程先转换成 SQLite。局部内容恢复不能误路由到整版恢复；普通缩短不能静默撤销保护。
- `generation-task`、`model-text`、`model-text-deepseek` 是本库保留的可选 Agent 适配实现，不是通用剪辑 Skill 路由、W14 或其他工作流的原子依赖。运行 Agent 管理生成调用；`raven-script-generation` 负责需求规格、候选评审、结果回接与剪辑。
- 其他尚无复杂入口的场景仍待建设；识别意图不等于实际覆盖。

## 访谈与多机位

- 访谈/多人播客的剪辑、机位选择、观点组织：`raven-interview-multicam`。仅做同步时走该入口的同步模式，不生成导演剪辑；只要原生多轨工程但宿主适配不可用时明确缺项。
- 已给参考/跟随文件与测量窗口或对应标记：`sync-offset-measure`；“哪个机位更精彩”需要复杂层判断，不属于偏移测量。
- 已给完整同步母版、shots 与节目音轨的参数编译：`multicam-plan-compile`。编译器不会替用户选讲话者或补全缺录时间。
- 一人单机位口播默认 `raven-speech-edit`；单机位双人访谈仍可走访谈复杂层，不因没有第二相机而杜撰反应。会议只需纪要/要点而无剪辑请求，不自动渲染视频。
- “换这个镜头但声音/字幕都不动”属于当前作品修改，保持段时间和节目轨，在 `raven-local-revision` 中引用访谈规则。更新同步后必须重算受影响源映射，不仅修改 style_bindings。

初始评测 Query 见 `evals/query-cases.jsonl`，其中包含正常、歧义、否定、连续修改与未支持情形。该文件是评测定义；只有留下独立实际路由输出和逐案判定后才能计算正确率。

## 课程与会议

- 内容提炼、章节剪辑、议题状态或知识链：`raven-course-meeting`。只要纪要、学习笔记或索引时停在对应交付，不自动渲染。
- 同样是多人素材，以交流与机位为目标时走访谈；以议题状态、决定/异议或先修依赖为目标时走课程会议。软件点击教程仍优先软件教程。合用时共享一份作品。
- 已明确单元、证据区间、出现实例和依赖的纯映射：`evidence-plan-compile`。“选重点”“这算决定吗”不能路由到此原子。
- 速查复习与零基础教学有不同先修条件。用户指定的反例、否定与未决状态优先于压缩时长；已有作品的局部修改先读当前版本。

## 体育、游戏与直播高光

- 选择精彩事件、讲清动作与结果、制作回放：`raven-event-highlights`。先区分体育、游戏、直播，短 Query 也可能需要内容判断。
- 只测量明确区间的逐帧亮度差或音频能量：`media-signal-scan`。没有阈值命中不能推断没有高光；逐帧测量也不是完整理解或事件召回证明。
- 已指定内容单元、事件阶段、回放身份和字幕：`event-plan-compile`。事件身份和成功标签由上层提供，编译器只核对映射。
- 安静策略、未进球或未完成动作同样可以有价值。回放必须可见标注，同一事件不因重播变成多个成绩；规则、游戏时钟与裁判判定需要实际证据。
- 只要分析/索引则不渲染；已有作品局部反馈沿用 `raven-local-revision`。课程提炼、电影解说仍分别去相应场景。
- 明确 0.5–2 倍恒速回放可由 `timeline-render` 的 clip.speed 执行；事件选取、完整性、回放身份仍由 `raven-event-highlights` 判断。跟踪竖屏裁切、速度曲线和光流补帧须核当前工具，缺能力则保留缺项，不能把普通变帧采样声称为光流。公开严格 `evidence-plan-compile` 的证据单元不能直接绑定变速 clip（`EVIDENCE_RETIMED_CARRIER_UNSUPPORTED`）；持久普通 `evidence_protection` 在明确授权 clip 与 `scope.evidence_mapping:true` 后可按范围映射合同处理恒速，不认证严格来源完整性、样本／像素冻结或声学语义，见[证据合同](../contracts/evidence-contract.md)。

## 参考稿与识别稿核对

明确指定两稿、字段、版本和比较规则，只要求列字面差异：`transcript-reference-compare`。要求判断哪句听错、是否改变原意、怎么纠正或怎么剪：`raven-speech-edit`先负责内容判断，按需调用对照原子。原子不把参考自动当真值；无参考不能虚构。`只核对`不提交作品或修改媒体。

## 生活、旅行与活动

- 人物经历、地点体验、家庭记录、活动回顾和拍摄方案：`raven-vlog-journey`。只有拍摄清单/分析时不渲染；风景素材不自动等于完整旅程。
- 明确源范围和音量淡变参数：`audio-envelope`。自然声音衔接、安静陪伴、感动等判断由复杂层决定；原子不挑环境声或保护对白语义。
- 地点/时间/人物关系需要实际证据；“按文件时间排”先核对时间来源与异常，mtime不认证事实顺序。无路径画面时可做诚实视角观察，不能假造路线。
- 已有片子的局部自然语言修改：`raven-local-revision`并引用Vlog规则。同作字幕、手工排序与冻结音轨不被重建覆盖。
- 演出以参与体验为目标走活动；以完整表演或精彩事件为目标可调用高光规则；以音乐视觉结构为目标的音乐混剪走`raven-music-montage`。商品效果/购买转化目标不能被普通旅行入口吞掉。
- 本库已有明确片段 0.5–2 倍恒速；自动稳像、速度曲线、光流补帧、地图动画、实时拍摄和原生剪映导入仍需核当前工具能力。能分析和制订方案不等于这些动作已经完成。

## 新闻、纪录与人物

- 有来源的事件解释、纪实观察、历史资料编排和人物叙事：`raven-documentary-story`。分别识别研究/采访拍摄方案/纸上剪辑/成片/修订，分析不自动渲染。
- 剧情影视解说走`raven-film-recap`，多人谈话的机位组织走访谈；人物原话为证据而重新组织非虚构故事时由纪录入口负责，可调用访谈规则但保持同作。
- “核实这段原话是否改变原意”属于复杂内容判断；已知单元和区间的映射才去`evidence-plan-compile`。字幕文字覆盖不认证事实、原声或充分标识。
- 历史事件时间、拍摄时间、页面发布日期、文件修改时间分开。历史素材不能冒充最新现场；原片已混剪时不可用片长测事件耗时。
- “只把已核实的日期从A改B，其他不动”走局部修订；“新证据推翻了结论，重做受影响部分”需要纪录内容判断和当前作品版本。来源不足不编造人物、观点、同期声或结局。

## 音乐混剪

- 音乐与画面结构、卡点取舍、视觉母题、表演/歌词/视觉循环的编辑：`raven-music-montage`。分析/选曲/方案不自动渲染或生成音乐；明确点位队列直接调用原子。
- `cue-alignment-check`只把音乐源点映射到当前音轨时刻，与明确clip/frame_offset比较。它不识别强拍/动作；工具SUCCEEDED而result.status=MISALIGNED仍需处理。
- 音量峰不等于重拍，固定间距不等于乐句；没有模型/听检时保留候选身份，不称自动识别通过。
- 体育以真实事件选择为主走高光，以音乐组织多素材为主走音乐混剪；旅行以经历/路线为主走Vlog，以视觉母题为主可走本入口；保持一份作品。
- “音乐不动，只让画面松一点”走同作修订并引用音乐规则。歌声翻译、音乐生成、速度曲线/分轨/跟踪/原生工程缺执行能力时明确缺项；明确画面片段 0.5–2 倍恒速可用，但不能把音乐源时钟和主片源时钟混为一谈。

## 节奏与时长重构

已有作品的紧凑、舒展、时长预算或重新分配节奏走`raven-pacing-restructure`，继承原题材内容协议；精确切点/音量队列直接原子，普通字幕恢复走局部修改。从零制作仍由题材入口主导，不能仅按“短、快”关键词抢路由。

软目标不是硬截止；冻结源内容不等于冻结位置；静音/熵分数不决定创作。分析/方案不提交，清晰修改直接按当前版本执行。本库可对明确片段执行 0.5–2 倍恒速，并按归一化帧数重算预算；速度曲线、光流补帧和原生编辑器接管须核当前工具，不因有风格卡就声称支持。既有硬时长拒绝不能因新增可选速度字段自动改判。

## 参考片分析与风格适配

- 分析参考叙事/节奏/构图/声画/色彩/文字，提炼机制并用于目标素材：raven-reference-style。先识别analysis/plan/final/revision，保留当前题材规则与作品主风格。
- 仅缩短/舒展走raven-pacing-restructure；用户明确要求按参考改变节奏时走参考适配并复用节奏约束。参数完整的LUT应用直接color-lut-apply，不自动挑风格。
- 未提供可查看参考时继续目标素材盘点，索取必要参考；截图只支持可见静态线索，不宣称听过音乐或看过完整节奏。
- 多参考按维度分工；原话/事实/保护区间优先。不可用HDR/Log、复杂动效、跟踪、光流等分别标缺项，不把参考相似度当成成片质量。
- 风格卡按任务按需加载，单次reference_profile不自动变为长期个人默认。

## 图文、脚本与生成补足

- 图文/图片/脚本制作声画短片，或已有作品补生成画面：raven-script-generation。先判analysis/plan/asset/final/revision，脚本与分镜不自动提交模型任务。
- 明确图片、逐帧裁切矩形和时长可直接still-image-render；“做得有故事感”“镜头该怎么动”是复杂决策。静图运镜不冒充图生视频模型或主体动画。
- 完整实拍剪辑按题材入口；图像只做封面而不做视频不属于本工作流。已有合格候选可评审剪辑；尚无候选而当前 Agent 有实际能力与授权时先生成候选再评审；能力不可用或生成后仍无合格候选时，仅生成阶段标 `capability-unavailable`，继续可完成的脚本、分镜和已有素材剪辑。
- 局部生成修订保存原资产，检查整片副作用；与纯时间线剪切分开。需要数字人或口型分别检查当前 Agent 的执行能力；本库可选本地生成账本没有媒体 Provider 适配时不能代替真实服务，不因已有风格卡就承诺实现。
- 外部任务超时先查原任务，UNKNOWN不等于失败；下载失败不能自动再生成。原文、锚点或模型参数变化使有关候选与QC失效。

## 多语言本地化

- 翻译字幕、双语、译配、地区表达适配、已有作品只改一处译文：raven-localization。语言、地区、字幕/声音/口型分别判断；已有明确要求不重复问。
- “海外版”而语言或是否改声音不清时问一个决定交付物的问题，仍可做源稿核对；只要字幕不生成声音，只要计划不提交付费任务。
- 指定译文、映射、字幕窗口、音频和profile可直接localization-plan-compile；字面检测不认证译义。既有同语种字幕纯样式走caption-burn或原子修订；同语种语义精剪走题材Skill。
- 源声克隆／口型是不同真实服务能力；当前 Agent 未实际接通并回读结果时不得冒充已实现。批量语言先由本地化决定每语种内容，W16 raven-multiplatform-batch负责本地明确版本队列；当前仍无远端服务队列与全语种认证。
- 多目标或局部请求仍保留同一作品父版本和修改范围，主风格不自动被翻译策略替换。

## 多版本适配与批量交付

- 现有作品的多用途、长短、横竖画幅、主题拆条与每版人工修改：raven-multiplatform-batch。先区分完整换格式与内容重组，不能只因句子短就走原子。
- 明确矩形裁切且不需构图判断：video-reframe。只导出已确定store/version列表：work-batch-render。指定父版本及范围候选派生：work-variant-create。多文件纯转码不凭数量唤起叙事改编。
- 多语言表达仍由raven-localization负责，W16管理各语言独立版本与队列；用户只要字幕不要配音时保留交付范围。
- “把竖版做得更适合手机”含读屏与构图判断；“裁成9:16”只有比例也可能缺主体范围，先观察素材并按用途决定保全还是裁切。已有明确矩形则直接执行。
- “恢复昨天的批量导出”先查manifest和回执，不重新剪所有版本；历史成功不等于当前人工版已导出。只分析或给方案不启动渲染和发布。

## 本地语音识别

只需转写已有音视频且模型／源／音轨／时间与语言参数明确时，调用speech-transcribe-local；删口癖、去冗余、选择take或判断“讲得更自然”仍走raven-speech-edit。语言标为中文不保证素材有中文语音，文件有音轨也不保证存在对白。模型识别不到词与结构异常分别记录；不能把它们直接转换成删除静音任务。指定云服务时不能静默换成本地模型。

## 解释画面与叠层

“在这段解释旁边加一张看得懂的图”需要语义和构图，进入当前场景复杂Skill，口播用raven-speech-edit；明确给定素材、帧区间和矩形才直接visual-layer-render。同一作品的修改进入visual_layers与scope.visual_ids，不把独立MP4当作已更新工程。
