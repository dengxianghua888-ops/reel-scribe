# 录屏裁切与定时高亮

调用 `screen-focus`，字段与实例结构见 [教程合同](../../contracts/tutorial-contract.md)。源哈希、crop、output、highlights 必须明确。矩形使用未裁切源视频像素，时间使用该源文件时间，半开区间。

不使用中心裁切近似用户指定目标。拒绝旋转元数据、非方形像素、奇数裁切坐标/尺寸、越界区域、裁切后不可见的高亮和非等比输出。复杂层决定是否牺牲导航/状态区域；本操作不会判断 UI 是否可理解。

输出 focused.mp4 与 focus-map.json；音频流复制，时长保持。当前仅固定裁切和矩形框，无缩放动画、光标重建、跟踪、蒙版或隐私遮挡。框选不是脱敏，不可冒充已遮挡敏感数据。

先做时间线剪辑再聚焦时，必须重新给出输出画面坐标/时间；若先处理源片再剪辑，登记派生源哈希及原源引用。执行器 [editing_runtime.py](../../runtime/editing_runtime.py) 与 [实现](../../runtime/tutorial_ops.py)。

可选`coordinate_space`允许调用者明确完整展示图尺寸与预期实际源尺寸，执行精确展示→源
坐标转换。详见教程合同。不能把带黑边/窗体边框、镜像或已裁切的截图当完整展示图；
源尺寸不匹配、比例不一致、映射结果非整数均拒绝，不偷偷取整或猜偏移。成功后查看
coordinate_audit和实际抽帧确认选区，不能把转换成功当选对字段。旧默认仍是源像素。
