# 胶片质感（显式参数）

调用 `operation: film-texture-apply`，字段见[胶片质感合同](../../contracts/film-texture-contract.md)。命令从库根运行：`python3 runtime/editing_runtime.py run --request /absolute/request.json --work-dir /absolute/new-run`。需要 numpy。

- 三种效果按固定顺序施加：光晕 → 暗角 → 颗粒。每种都可以省略，参数都要显式给出，没有“胶片预设”。
- 颗粒带种子：同一请求得到同样的像素。`per-frame` 每帧一组噪声；`static` 每帧相同，看起来像镜头上的脏污，一般不用。
- 回执在抽样帧上用同一套计算重算预测值，与解码后的输出比较（轻微低通后中位 ΔE2000 不超过 3），并逐项报告光晕增加的光、暗角前后的角落与中心亮度比、颗粒的亮度标准差。
- 质感属于画面，应在调色之后、字幕和叠层之前施加，否则字幕也会带上颗粒和暗角。
- 与 `color-lut-apply` 相同，只接受零起点恒定帧率、无旋转元数据的输入，只处理第一条视频流；VFR、非零起点或带旋转的素材直接拒绝，不隐式转换。
- 调用方取消，或连续 300 秒没有完成一帧时，解码与编码进程都会被结束，返回 `TEXTURE_CANCELLED` 或 `TEXTURE_STALLED`，部分输出保留。

这些效果是参数化的近似，不是任何胶片型号的测量或仿真；是否好看、适不适合内容，由人看过预览再决定。
