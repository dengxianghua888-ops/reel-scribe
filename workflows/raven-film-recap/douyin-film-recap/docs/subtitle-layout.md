# 字幕坐标与分组边界

影视解说烧录使用 FFmpeg/libass。SRT 的隐式 ASS 画布不等于成片画布；渲染明确设置 `PlayResX=render.width`、`PlayResY=render.height`。`subtitle_font_size`、`subtitle_margin_v`（底部边距）、`subtitle_outline` 以该输出画布像素为单位，而不是隐式 384×288 脚本坐标。字体字号并不等于可见字形的精确像素高度，字体度量及描边会影响实际包围盒。

默认 1080×1920 下字号 62、底边距 250；改变画幅不会自动重选合适字号。字号必须正、底边距/描边非负；烧录前拒绝底边距达到画布高或字号超过画布高。可用值仍须检查行数、横向宽度、界面遮挡及阅读时间。不是“配置合法即所有文字一定可读”的保证。

TTS 有词界时，达到原有最短组时长的句末 token 加入当前组后封组；字符和时长上限仍优先。无词界按字符权重分配只属于估时，不是语音对齐。分行在硬上限允许时把闭合标点与前一字符留在同一行，避免孤立句号开行；极窄上限或无法容纳的标点串不能保证禁则。该规则不是中文分词、专名识别、否定关系识别或通用语义分组。

回归包含真实 FFmpeg 双分辨率合成底图的像素包围盒，以及移除 PlayRes 的旧坐标负例。公开中文语音参考字幕显示检查不证明 ASR、声文对齐或真实听检完成。
