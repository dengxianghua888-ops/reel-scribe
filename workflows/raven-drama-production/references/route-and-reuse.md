# 路由与现有能力复用

保留一个主任务和作品身份。下表的路由是创作职责分工，不要求同时调用五个 Skill 或重建五份计划。

| 用户实际请求 | 主入口与模式 | 本入口的作用 |
|---|---|---|
| “原创一个两分钟漫剧，先看剧本和分镜” | raven-drama-production / PLAN | 建原创设定与候选链，交完整文稿/镜头计划；不提交媒体任务 |
| “把这份已授权小说的某一段改成短剧” | raven-drama-production / 按请求选模式 | 保留原文证据与改编决定的区别；角色合并、视角变化或结局改写需在本次创作范围内 |
| “用现有剧情素材，按女主视角剪一条故事线，不加解说” | raven-film-recap 的原声剧情剪辑能力 / PLAN 或 PRODUCE | 以真实素材为事实与时间范围；需要新创场次时再调用本入口处理该部分，不能虚构已存在镜头 |
| “解说这部电影，解释人物为何这样选择” | raven-film-recap / 按请求选模式 | 不切换为原创写作，不把推断或套路补成原片事实 |
| “这部作品只缺一个雨夜走廊镜头” | raven-script-generation；在原作局部修改中结合 raven-local-revision | 读取原作约束和镜头缺口，限定补足范围；无需重新写全剧 |
| “只帮我写或修改剧本，不做视频” | raven-drama-production / PLAN 或受限 REVISION | 剧本、状态及必要影响说明即为目标；不要求图、音频或成片作为完成前提 |

用户明确要修改已有作品时，REVISION 与内容入口可组合，但仍是同一作品的一次限定任务。目标属于分析时使用 ANALYZE；承诺可编辑工程时，EDITABLE 还须说明是否真实目标工程、是否完成打开/读回，不把普通 JSON 草案称为 NLE 工程。

## 复用职责

- **W01 / raven-film-recap**：命题级人物知识、故事因果、揭示与声画责任；有原片时保留观察、推断和未知。原创创作决定不能伪装成观察事实。
- **W14 / raven-script-generation**：镜头规格、参考锚点、静图/生成候选、实际资产回接。
- **W13 / raven-reference-style**：按维度理解参考，把风格机制落实为作品规则和同素材对照。
- **W04 / raven-local-revision**：当前版本、保护、允许范围、候选、采用与恢复。
- **W12 / raven-pacing-restructure**：调整节奏时保住前提、反应、沉默和声音完整性。

这些职责来自固定线上版本 `0288db1a7c9ec3cbeb77673d5cf18279385c2340` 的研究，不表示本机安装或目标宿主验收。若可读取同版本原工作流，按实际任务加载对应部分；否则本包的逐场方法仍支持 PLAN，执行能力不得凭名字推定。

## 输入不足时的推进方式

已给目标、人物和事件，可先提出明确标注的创作候选；不要反复索要可合理假设的信息。影响核心故事、改编范围或制作约束的未知，列入待决项并继续无关部分。

没有实际媒体，不妨碍写脚本与制作需求；但实际资产数量、画面质量、声音时长、模型可用性保持未知。没有参考片内容时，不凭导演/片名猜测具体镜头；可先将用户表达转为可讨论的视角、节奏、构图和声音机制。
