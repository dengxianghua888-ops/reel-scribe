# 《归还钥匙》｜风格与资产规格 v0.1

本文件是创作候选设计。全部图像、声音、候选 take 和工程素材状态为 **PLANNED**；没有真实参考文件、生成任务、配音、成片或媒体 SHA。本文中的角色细节是拟议设定，不是从照片识别出的事实。

## 1. 本片风格规范

风格 ID：`return-key-style-v0.1`。拟议主风格：**用物件动作承载关系变化的克制日常剧情**。形态为有限动态、低饱和写实插画，不照搬任何导演或现成作品的具体画面。

| 维度 | 本片决定 | 可以变化 | 审查方式 |
|---|---|---|---|
| 叙事 | 随 C01 观察；父亲动机通过动作与归还逐渐显露；不进全知内心 | 字幕或对白可明确已有事实；不能凭表情新增心理定论 | 核各场知识表、台词与可见动作是否一致 |
| 画面 | 中近景为主，保持门、两人和手部的空间联系；门口与厨房各有一次稳定空间建立 | 钥匙首次卡顿、交接、试开可近取；表情不必每句切反打 | 看关键动作是否完整、人物视线是否有对象 |
| 运动 | 有动机才动：进门、工具操作、接钥匙、试开；主要镜头固定 | 可轻微跟随跨门槛，若不破坏动作识别 | 区分静图运镜与主体动作；动作失败不能靠推镜冒充 |
| 色彩/材质 | 灰、米白、旧木与黄铜；褪色蓝线圈是局部辨识点；保留阴影层次 | L01偏冷、L02偏暖，幅度小且有光源依据 | 逐场看角色衣色、肤色和钥匙材质；不要求全片像素同色 |
| 节奏 | 优先动作前提→行为→结果；对话后允许反应，不为固定秒数切镜 | 实测后可缩无信息停顿；手部交接与开锁结果不可省 | 先看因果和动作完整，再看是否拖沓；150秒是目标而非硬拼 |
| 声音 | 对白归属清楚；门锁/门铃/小锉承担空间与行动；主版无配乐无旁白 | 房间底噪随开关门变化；情绪可影响气息和停顿 | 单独听对白/动作；音效不能替代未出现的动作 |
| 字幕 | 后续若需要字幕，单层、低装饰、尽量避手和钥匙；不增加心理解释 | 文字换行按实际语音/画幅校准 | 台词逐句对应；人物画外音仍标正确归属 |
| 结尾 | 女儿的行动承诺与再入门完成小变化 | 可保留停顿和不明显笑意 | 不加金句或拥抱来强行扩大和解程度 |

本片不采用固定三秒钩子、每两秒切镜、统一推拉运动或所有段落配乐。以上是本作品选择，不构成剧情 Skill 的通用禁令。

## 3. 角色、造型与声音

### C01｜林青

- 身份不变量：32岁女性；窄而不过度消瘦的脸型；自然眉；低马尾，左侧分缝；说话速度适中，句尾较轻。避免用“悲伤女儿”这种抽象提示替代身份细节。
- 造型变体 `C01-V01`：深灰直身外套、米白圆领内搭、深色长裤；全片同款，无换装。肩线与袖口长度各镜一致。
- 声音规格 `C01-VOICE-V01`：普通话，成年女性自然中低音域，无拟造名人或真人克隆；D02/D03略收紧、D08有一个起句犹豫、D11更确定。情绪变化不等于换音色。
- 手位：P01由右手持、交、接、插入和转动。SH12左手轻推门，右手转钥匙。若制作中确需换手，应新增可见动作与状态记录，不能无说明镜间互换。
- 变化：进屋前手臂较贴身；接回钥匙后动作略放松。这个表演建议不构成内心识别结论。
- 参考控制：正面/三分之二侧面锚点控制脸、发型和服装；不让角色参考图附带的陌生房间或灯光自动进入场景。

### C02｜老林

- 身份不变量：63岁男性；短灰发；自然眼袋和手部年龄纹理；肩背轻微前倾但不演成病弱；声音略低、语句短。
- 造型变体 `C02-V01`：灰褐针织衫、深色长裤；袖口位置全片稳定，不在修钥匙镜头凭空卷起。
- 声音规格 `C02-VOICE-V01`：普通话，年长男性自然声线；不刻意沙哑。D06/D07像说具体事情，D12像接受次日买菜安排，不配“释然”音效。
- 手位：SH04左手接钥匙；SH06可短暂放自己侧台面，随后左手拿起；右手取锉、修整和放下工具；SH09左手递回，C01右手接。
- 动作边界：先停止工具动作，再递钥匙；不能边修边交；SH11之后不碰门把或门锁，不替C01完成试开。
- 参考控制：角色图只控制身份/服装；修整时的手势另用动作参考，不从静态头像推断手部正确。

两人的参考与声音身份独立。不得因为相同色调把服装串给对方，也不得在画外对白时把D07配成女声。

## 4. 场景、空间与道具

### L01｜走廊/门槛

从走廊正对门看，门铰链在左、门锁在右，门向室内开启。门铃在锁侧墙面。走廊偏冷的散射光，门内较暖，但不做夸张冷暖分割。

- SH01和SH12是同一门锁位置，保持锁芯高度、门上旧痕和蓝线圈比例。
- 门的可见状态：SH01关闭且钥匙未成功打开；SH02父亲从里面开；SH05进入后合上；SH11女儿出门并关上；SH12–13由女儿钥匙试开；SH15自然带上。
- 摄影左右可随机位变化，必须保留地理关系；不把固定“屏幕左/右”错误外推到反向机位。
- 门内短过道归入L01的门槛联系空间，不另设第三地点。

### L02｜厨房

门内短过道通向小厨房。台面一侧面向入口，父亲在台面近里侧，女儿在入口侧。两人同框时以父亲画面左、女儿画面右作为本场轴线基准。

- 台面有小抽屉和一把小锉，环境物件不应自动增加钟表、照片、纪念物或第三人痕迹。
- P01短暂放在父亲一侧台面，蓝线圈朝观众可见方向；再次拿起后位置不得留下第二把钥匙。
- 主光来自厨房窗的柔光加普通室内光；SH06–10连续时间，不无故改变天气和太阳方向。
- 小锉、门锁、门把、门铃、台面、抽屉列为环境配件，保留形状和位置连续；不另建主剧情状态线。

### P01｜旧钥匙

- 单把旧黄铜钥匙，椭圆钥匙头一侧有小凹痕，系褪色蓝线圈；没有其它钥匙或金属挂件。
- 身份稳定：形状比例、线圈颜色、凹痕所在侧保持。修整允许局部边缘变化，不得变成崭新银色钥匙。
- 结构化造型ID：修前为P01-V01，修后为P01-V02；都属于同一P01。L01-V01/L02-V01标本片同日空间视图，不新增地点。
- 起始条件：打开门有卡顿。修整后“是否能用”在E08试开前仍未被剧情内实测。
- 移交链：C01右手→C02左手（E02）→C01右手（E05）。台面暂放不改变角色保管责任。
- 末态：钥匙由C01持有；她自己开门、进门，没有再把钥匙留在父亲家中。

## 6. 从计划到实际素材的交接

实际素材回来后，分别记录真实资产ID/版本、可核的文件或宿主身份、参考控制范围、所属角色/造型、覆盖镜头、内容审查状态。只能在读到字节时计算文件哈希；不能用本表ID或提示词散列冒充媒体身份。

候选需分别检查：

1. 身份与变体声明是否错绑；这是B1可以设计和检查的数据关系。
2. 真实画面中是否串脸、换装、道具形变或空间漂移；这是B2实际媒体审查。
3. 动作中段是否正确；首尾静帧正常不能代替动作连续性。
4. 台词发声者、语气、停顿和实际时长；D07画外归属父亲。
5. 采用后是否仍符合当前版本与保护范围；有旧候选时不能只改版本号沿用。
