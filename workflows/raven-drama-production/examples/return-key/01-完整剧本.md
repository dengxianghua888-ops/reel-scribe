# 《归还钥匙》｜完整剧本 v0.1

状态：AI 拟议原创样例，**待用户评审，未采用到任何作品**。本文件只表达创作意图；所有对白、动作、空间与时间均未拍摄、未生成、未录音。150 秒为分镜排布估计，不是实测成片时长。

## 创作目标

一个已经搬出去的女儿，把父亲索要钥匙理解成收回她的出入资格；父亲却只是修好那把卡顿的钥匙，再放回她手里。结尾由女儿主动决定明天回来，而不是父亲用一段解释劝她留下。

不证明两个人过去没有矛盾，也不让一次归还消除所有隔阂。只完成一个小变化：她从“我要交还这个家的入口”，走到“我仍然可以自己打开门，也可以自己选择再来”。

- 目标形态：有限动态、写实插画质感的剧情短片；关键动作要可读，不以静图替代钥匙的真实移交与试开。
- 计划时长：150 秒。两角色、两地点、三场戏、15 镜、12 句台词，无旁白。
- 观众视角：主要随林青观察；不提前进入父亲内心。
- 声音：门锁、门铃、衣料、小锉与钥匙、室内底噪。主版无配乐。
- 主道具：P01，一把旧黄铜钥匙，钥匙头系褪色蓝线圈。门锁、小锉、台面、门铃是环境配件，不开独立剧情状态线。

## 人物、地点与片前背景

| ID | 内容 | 本片任务 |
|---|---|---|
| C01 | 林青，32 岁，女儿。刚搬出父亲家，灰色外套、米白内搭，低马尾 | 带来钥匙并完成她以为应做的交还；后来重新决定是否回来 |
| C02 | 老林，63 岁，父亲。灰褐针织衫，动作慢但不刻意衰弱 | 修整女儿提过卡顿的钥匙，交还给她；不主动长篇解释关系 |
| L01 | 老公寓家门外的走廊，含门槛和可见门扇 | 三次门的状态变化：卡住→父亲开门→女儿自己打开 |
| L02 | 与入户短过道相连的小厨房，靠门一侧有工作台面 | 误解松动的场所；修钥匙动作在台面完成 |

BG01 为拟议片前设定：林青以前提过钥匙不好开。今天父亲发来一句“走之前，把钥匙给我。”，没有说“还”或“收回”。主版不插手机截图，也不依赖闪回：D02 复述消息，D07 交代父亲记得卡顿。观众能够从主版获得必要因果。

人物心理属于作者设定。画面只呈现行为和台词，不把“低头”“停顿”自动写成观众已经确认的内心事实。

## SC01｜门外，傍晚｜00:00–00:45，预计45秒

**起点：**钥匙在林青手里。她把父亲的消息理解为要收回钥匙，准备快速办完这件事。\
**变化：**钥匙移交给父亲；父亲请她进屋，尚未说明为什么索钥匙。

**SH01｜00:00–00:08｜8秒**

门锁与林青的手。蓝线圈贴在指背上。

她把钥匙插进锁孔，转了一下，没有打开。停半拍，又轻轻试一次。她没有猛拧。钥匙抽出时刮出一声短响。

镜头不放大破损，不把它拍成危险事故。这个卡顿只是她熟悉的一件小麻烦。

**SH02｜00:08–00:18｜10秒**

走廊中景。林青按门铃，把钥匙拢进掌心。

门开。父亲站在门内，先看见她，再看向她的手。

**D01／C02：**“带来了？”

林青点了一下头。

**SH03｜00:18–00:25｜7秒**

林青近中景，父亲在画外。她把手松开一点，露出蓝线圈。

**D02／C01：**“你不是说，走之前把钥匙给你。”

“给你”说得平，不加“还”。她以为这句话的意思，和父亲写下它时的意思并不相同。

**SH04｜00:25–00:35｜10秒**

门槛两人同框，手的动作可见。

林青把钥匙放进父亲张开的手掌，自己的手收回。父亲握住钥匙。

**D03／C01：**“东西都搬完了。”

父亲看她一眼，没有接“搬完了”这一层意思，侧身让出门口。

**D04／C02：**“先进来。”

钥匙在父亲手里，不能下一镜又出现在女儿口袋。

**SH05｜00:35–00:45｜10秒**

从门内短过道看向厨房。父亲先走到台面前，女儿停在入口，随后跟进去。门自然合上。

父亲将钥匙带入厨房，女儿双手空着。两人的距离没有立刻拉近。

## SC02｜厨房，连续｜00:45–01:45，预计60秒

**起点：**钥匙由父亲持有，林青仍认为以后应按门铃。\
**变化：**修整与归还提供新的行动证据；她说出误会，父亲邀请她试开。能否开门仍未得到验证。

**SH06｜00:45–00:55｜10秒**

台面侧面中近景。父亲把钥匙放在自己一侧，抽开小抽屉，取出一把小锉。蓝线圈垂在台面边缘。

不要切成过快的工具蒙太奇。让林青与观众有时间辨认他准备做什么。

本镜结束前，父亲重新拿起钥匙。台面上的是短暂放置，持有责任仍属于父亲，不构成第三次人物移交。

**SH07｜00:55–01:07｜12秒**

父亲上半身与手同框。他对钥匙边缘作轻微修整。手与钥匙接触需可读，重点是他停顿、查看、再修整的具体动作。

林青在画外。

**D05／C01：**“以后我按门铃。”

父亲停一下，看看钥匙，再继续。

**D06／C02：**“你这把总卡。”

小锉的短声结束后留出一点安静，不以配乐提示“温情反转”。

**SH08｜01:07–01:17｜10秒**

林青中近景。她的视线从父亲脸上落到手上。

**D07／C02，画外但明确归属父亲：**“上回你说过。”

林青没有立刻笑。她看着手上的动作，原来确定的一种理解开始松动。镜头只是提供这个可能，不能凭眼神断言她已经理解父亲所有心意。

**SH09｜01:17–01:31｜14秒**

回到能同时看见两人的中景。父亲停锉，将工具放回台面。

**D08／C01：**“我以为你要收回去。”

父亲把钥匙递向林青。她伸手接住，父亲松手，蓝线圈落进她掌心。

**D09／C02：**“往里推一点。别硬拧。”

交接前后要同镜可辨。修整和交还支持“他不是要扣下钥匙”的理解，但钥匙是否已经能用，仍要留给下一场。

**SH10｜01:31–01:45｜14秒**

稍远的厨房景别。林青看了一眼掌心里的钥匙，抬头。

父亲抬下巴指向门口。

**D10／C02：**“试试。”

林青握好钥匙，向门口走。父亲跟到过道，不抢先替她开门。停顿是她重新决定怎么进入这个家的时间，不是无事可拍的空镜。

## SC03｜门外/门槛，连续｜01:45–02:30，预计45秒

**起点：**林青带着已修整但未试开的钥匙，父亲在门内。\
**变化：**她自己打开门，主动约定明天回来，钥匙留在自己手里。

**SH11｜01:45–01:53｜8秒**

门槛侧面。林青出门到走廊，把门轻轻带上。父亲留在门内，手离开门把。

钥匙一直在林青右手。不能让父亲在试开时偷偷拉门来制造成功。

**SH12｜01:53–02:03｜10秒**

回到与 SH01 相近的门锁景别，但不是复用一段旧画面。

林青插入钥匙，用空着的左手把门往里推一点，右手缓缓转动钥匙。锁舌响了一下。她停一瞬，继续推门。

门的运动和钥匙转动要连贯；本镜不用字幕解释“修好了”。

**SH13｜02:03–02:13｜10秒**

门打开，林青与父亲重新同框。父亲没有扶门或碰锁。

林青先把钥匙抽出来，再看向父亲。

**D11／C01：**“明天我买菜。”

这是她此时作出的行动承诺。此前任何状态表都不应提前写她已经决定明天回来。

**SH14｜02:13–02:22｜9秒**

保持轴线，父亲侧身，留出一人通行的位置。

**D12／C02：**“那我不买了。”

不用强调笑容或“终于释怀”。让这句回答像日常安排，被接住的是她的提议。

**SH15｜02:22–02:30｜8秒**

从屋内看门槛。林青跨进来，钥匙仍在手里。她经过镜头时，蓝线圈轻晃。

父亲朝厨房走，林青跟进。门自然带上，锁舌声比开头短而干净。切黑。

**结束。**不补旁白、金句、拥抱、童年蒙太奇或“家永远为你开门”的片尾文字。

## 合理闪回变体 V-FB01｜不替代主版

目的：验证非线性叙事的字段表达与状态隔离，不作为主版必要因果补丁。

在 SH08 内分配 4 秒主观短回忆：林青想起当日父亲发来消息“走之前，把钥匙给我。”。可以拍她较早在同一走廊看手机；L01 不变、人物仍只有 C01，不显示额外人物。画面状态为 P01 当时由 C01 持有，时间层为 `past-recall`。它是对消息这一事实的回忆，不是对父亲动机的全知证明。

变体仍保持 SH08 共10秒：3秒当下反应→4秒过去片段→3秒回到当下。主版 D07 的语句可以保留在两侧当下镜头；不要把父亲当下声音伪装为回忆中的原始录音。若声音无法清楚区分层级，改为完整保留主版，不勉强添加闪回。

回到当下时，P01 仍由 C02 持有；SC02 的归还仍发生在 SH09。闪回不能把当前持有人回写成 C01，不能撤销已经发生的 E02。变体新增的具体镜头子项、媒体与声音均为 PLANNED，尚未制作。
