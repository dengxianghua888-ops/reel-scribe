# 剧情创作与制作交接

版本：0.1.1-experimental。本地候选版已注册 W17，提供剧情方法、完整文本样例及可选领域检查；真实媒体、独立内容效果与宿主兼容仍需各自证据。制作阶段依实际任务授权、能力及结果推进。

## 先确定交付模式和当前作品

从用户请求提取模式、故事范围、目标时长、表现形式、必须保留/禁止改变、允许修改范围与参考风格。明确要求优先；只要剧本或评审时停在相应交付，需求未明确到媒体制作时先做 PLAN。已有作品先读取当前修订及手改，不因换剧情入口新建另一份作品权威。

六类易混任务及复用关系见[路由与复用](references/route-and-reuse.md)。本入口可用于离线创作与 PLAN；W01/W14 等从本库按需加载。需要实际制作时再检查当前宿主能读、能执行、能读回哪些能力。

首次建立内容包或调整字段时读[最小合同](../../contracts/drama/01-最小合同.md)；绑定已有 Work/Storyboard 或准备采用时再读[模型映射与采用设计](../../contracts/drama/02-现有模型映射与采用设计.md)。沿用 TaskSpec/EditorialPlan/现有作品身份，领域附件只补剧情语义，不另造工程、预算账或最终交付状态机。

## 围绕场次推进

1. **定故事与表达。** 写清人物目标、阻碍、选择、代价和结局；确定视角与观众何时知道什么。按复杂度使用段落/场次，不强制短片补空的幕结构，也不套固定钩子或镜长。
2. **准备当前场。** 装配该场必要的角色、地点、道具、知识/误信、未回收伏笔、风格及保护项，注明所依据的版本。实际采用态与设计假设分开；完整初稿可沿候选链草拟，但不能把候选写成用户已接受。
3. **写场景候选。** 同时交动作/对白、Beat、前后状态与变化依据；剧情时间、揭示顺序和梦/回忆等层级明确。具体方法见[逐场工作流](references/scene-workflow.md)。
4. **做制作方案。** 给镜头用途、Beat 覆盖、起点—动作—终点、角色/服装/场景/道具引用、声音归属和预计时长。风格需落到可审查的画面与声音决定。计划参考、真实参考、候选 take、采用媒体各有身份，不用计划路径冒充实际素材。
5. **检查并交接。** 对照[审查与修订](references/review-and-revision.md)报告结构错误、语义疑点、媒体未测项与影响范围。实际采用继续走已有作品的版本/范围机制；本次只评审时交付候选和影响清单即可。

历史场次变化后，重新装配相关后续场次的状态，区分确定依赖失效和语义待复审。一个 Beat 可由多镜承载，长镜可承载多 Beat；显式闪回和复演合法，生成片段不等于剪辑镜头。

轻量程序使用与结果边界见[本地检查](references/local-checks.md)。它只消费显式内容附件，不会生成素材或提交作品。

## 到实际媒体时

按已明确的镜头规格交给真实可用工具，沿用用户已有授权与范围。运行宿主负责模型、凭据、任务、预算和恢复；Skill 负责提出需求、判断候选及核对产物。缺一项能力，只标明受影响部分，继续能完成的独立交付。

实际媒体返修、听检或风格一致性审查时，读[媒体质量与局部返修](references/media-quality-and-revision.md)。先确定实际可感知的输入范围，再选择编码保持、完整声音覆盖和风格检查的方法；源素材相同、模型转写成功或导出成功分别只证明其本层结果。

扩大制作前，先用小样检查双人同框的身份/衣物、同一空间内外的机位关系，以及一组关键道具的前后状态；按任务需要选择代表镜头，核实后再扩展。分别记录目标媒介与实际输出媒介：写实剧照彼此一致，也不能自动算作原插画或连续动画目标通过。依已有任务授权做内部审查，修正明确错绑；风格分歧或缺失能力保留待审，继续可独立完成的部分。

获得候选后读取实际内容、身份与时长，再安排剪辑。结构/声明正确不证明画面身份、动作、声音或风格正确；参考首尾帧也不证明中间动作连续。完整制作要求实际输出读回及完整看听，不能以工具 success、计划时长或单帧正常代替。

## 交付

交付本次模式要求的剧本、领域附件、风格/资产与镜头计划、修改影响及检查记录；实际制作再附真实媒体和可续编结果。报告采用原有 PASSED / DEGRADED / BLOCKED 口径，限定为本次目标与证据范围；必要项未做如实说明，不以未做媒体否定已完成的纯 PLAN，也不把 PLAN 通过升级为成片通过。

需要完整示例时读[《归还钥匙》剧本](examples/return-key/01-完整剧本.md)，再按需要读[风格与资产](examples/return-key/02-风格与资产规格.md)和[分镜与状态轨迹](examples/return-key/03-分镜与状态轨迹.md)。样例为待评审创作候选，不是实际接受、生成或成片证据。
