# 本地命令与验证边界

在仓库根运行；纯剧情检查使用 Python 标准库，不需要模型、Provider、Agent 或媒体工具。媒体相关 Work 操作仍遵守原运行时依赖。

```sh
python scripts/drama_tools.py validate workflows/raven-drama-production/examples/return-key/drama-content.json
python scripts/drama_tools.py context workflows/raven-drama-production/examples/return-key/drama-content.json --scene SC02 --budget-chars 32000
python scripts/drama_tools.py variant workflows/raven-drama-production/examples/return-key/drama-content.json workflows/raven-drama-production/examples/return-key/variant-FB01.json
python scripts/drama_tools.py impact BEFORE.json AFTER.json
python scripts/drama_tools.py verify-package workflows/raven-drama-production/examples/return-key/PACKAGE-MANIFEST.json
```

各命令可加 `--output 新文件.json`；不会覆盖已有证据。PASS 返回 0、FAIL 返回 1、UNCERTAIN 返回 2。影响报告只读；不得把退出码 0 当作成片通过。

准备现有作品的附件：

```sh
python scripts/drama_tools.py prepare-attachment PATH/TO/PACKAGE-MANIFEST.json --store /absolute/path/work.sqlite3 --base-version ACTUAL_READ_VERSION --output prepared.json
```

它只复制成员并返回 note 引用，**不采用**。将返回 `reference` 放入最近完整 WorkDocument 的 `notes.drama_domain_ref`，在原 scope 的 `note_keys` 中显式允许该键，再通过现有 timeline-revise 和 work-version commit。最后 work-version read 应返回新的真实版本及附件校验报告。无真实素材/作品时不运行此步骤。

运行自测：`python -m unittest discover -s tests/drama -v`；完整工程集成用 `python -m pytest tests/drama tests/runtime tests/packaging`。部分 Work/媒体测试需要 `EDITING_FFMPEG/EDITING_FFPROBE` 指向实际工具；不要把跳过测试写成通过。

校验器可查 ID、引用、显式状态变化、知识依据时序、覆盖、时长、声明来源、闪回边界和预算。它不能从任意自然语言可靠裁决角色是否知情、表演是否成立；结构化疑点单列，真实视听检查保留 NOT_RUN。样例全部媒体仍为 planned，150 秒为计划值，不是已制作的短片。
