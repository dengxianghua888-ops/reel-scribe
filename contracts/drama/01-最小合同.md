# 剧情领域合同 0.1

入口：[raven-drama-production](../../workflows/raven-drama-production/SKILL.md)。这是可独立使用的内容附件和本地校验合同；不是剧情视频生成器，也不创建第二个作品数据库。设计来源为 2026-10-25 B0/B1-D 冻结评审包；可执行边界以本合同、校验器及测试为准。

## 内容与证据

内容根的 `schema=drama-content/0.1-design`（兼容冻结案例）或 `drama-content/0.1`。任务、人物/地点/道具、命题、事件、快照、场次、Beat、镜头、对白、素材、风格引用保留稳定 ID。完整字段见[样例](../../workflows/raven-drama-production/examples/return-key/drama-content.json)，机器跨字段规则在 [drama_domain.py](../../runtime/drama_domain.py)。

- `task` 持有模式、目标时长、约束和保留项；PLAN 不授权生成、渲染或采用。
- `entities` 的身份不变量与 `variants` 的服装/外观分开；同名不合并 ID。
- `propositions.truth` 为该故事层的设定真值；`knowledge.attitude` 为角色或 AUDIENCE 的 `believes_true/believes_false/unknown`。误信合法，观众所见不自动成为人物所知。
- `valid_from_event` 阻止以未来发生的结果为当前已知依据。`basis.kind` 区分 authored/observed/inferred/unknown；脚本和提示词不属于真实素材观察。
- `scenes.pre_state/delta/post_state` 表达明确变化。`candidate_dependencies` 是候选链依赖；旧前场变更后下游要重审，不能把候选链直接当权威。
- 快照 `authority=fixture_assumed` 只是创作基线。实际采用以 Work 读回为准，不能自填采用回执。
- required Beat 必须有镜头承载；一镜多 Beat、多镜同 Beat 合法。估计时长与实际时长分开。
- `visible_characters` 表达计划中的可见人物；`asset_refs` 表达需求与上下文，不证明实际像素消费。
- planned 素材的 `actual_binding=null`。实际本地媒体绑定要有 `path/sha256/size_bytes`；领域检查只核声明，采用边界额外核字节，视觉和声音质量仍需查看和听检。
- CAP 对白字幕槽可 `requirement=optional/selection_status=undecided`；必要消息文字属于剧情画面，不等于用户已选择字幕。

## 上下文、闪回与变化影响

上下文装配返回所用版本、必要前态/因果/约束、相关实体与变体、候选依赖和缺项。预算单位是 Unicode 字符，按实际装配 JSON 计数，不冒充 token。超限须返回 FAIL 并保留完整候选上下文，不悄悄删掉必要信息。外部风格文档未加载须显式报告，不能称上下文完整。

嵌入闪回以 `edit.replaces_shot_ref` + `leaf_shots` 替换父镜头：父组不重复计时。叶子的 `story_layer/location_id` 覆盖场默认呈现层，不改当前世界物理状态。`boundary_states.state_scope=partial` 只保证列出的字段。`dialogue_rebindings` 迁移对白承载，避免父子重复播放。

变化影响分为 `deterministic_impacts` 和 `semantic_review_impacts`，保留原因、版本、未受影响项与仍未知的真实消费。影响报告输出计划范围；宿主 clip/audio/caption ID 需要显式映射，不能把 shot ID 直接当宿主 ID。字幕样式不自动重配音；角色服装只影响声明可见的镜头，未知消费另行核实。

## 包与采用

`PACKAGE-MANIFEST.json` 使用 `drama-package/0.1`，包括 `package_id/package_revision/content_path/work_binding/members`。每个 member 是相对路径、真实 SHA256、字节数；禁止重复、自引用、目录逃逸及符号链接。清单不自哈希，外部引用持其哈希。内容和清单均保持 `unbound_design`、真实作品字段为 null；采用不反写内容包，避免身份循环。

`notes.drama_domain_ref` 的字段和采用流程见[映射](02-现有模型映射与采用设计.md)、[本地命令与验证边界](03-本地验证与采用.md)。无该字段的旧作品不要求迁移。

## 结果语义

单项结果为 PASS/FAIL/UNCERTAIN/NOT_RUN/NOT_APPLICABLE；UNCERTAIN 需审查或改正声明。机械检查通过不代表因果、表演、风格、声音或成片质量通过。本地采用要求领域结构 PASS；不能靠传入“已检查”字符串绕过。实际最终交付继续使用现有 PASSED/DEGRADED/BLOCKED 口径。

本实现不做自然语言矛盾证明、自动剧情创作、Provider 调度、宿主 UI 接管或完整影片验收。真实媒体和审美证据另行记录，不继承样例的文档检查结果。
