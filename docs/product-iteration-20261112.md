# Reel Scribe 产品迭代：首个可执行闭环

基线：`46a56125dae30dc0da6fdee4b111a54a5a3d71e7`。本轮从既有风格卡、Work 文档与范围保护继续建设，不另建权威状态，不增加一批未验证风格卡。

## 本轮能力

1. 已选风格卡 + 显式包装参数 → 摘要绑定的配方 → 范围校验后的普通 Work candidate。
2. 当前文档 + 候选 → 阶段依赖变化与复验计划。字幕包装不被误称为重新生成配音；未变依赖不等于已经复用缓存。
3. 候选沿用既有 work-render preview_candidate 与 work-version commit；正式头不因配方编译或影响分析而改变。

配方首版仅支持当前渲染器确有实现的字幕字号、颜色、边距及指定音轨增益。不要称其为完整“悬疑风格/纪录风格引擎”：叙事、选段、留白、跨镜头因果、真实声音处理效果仍由工作流和素材验证。全局字幕样式会影响全部字幕，不能暗示只修改其中一句。

## 使用顺序

- 读取 Work 当前版本，确认任务、素材、锁定范围及真实能力。
- 选择现有风格卡并显式指定参数；编译配方前记录卡片的路径与 SHA-256、配方摘要、基础文档摘要及版本。
- 审查候选差异与影响报告；需要先看效果时，预览候选而不提交。
- 用户已授权实际修改时，经现有提交接口核对当前头与保护范围，再导出新版本。
- 对最终输出重新核技术、内容、视觉、听感和编辑器条件；未运行的项保持未运行。

精确请求结构见[配方合同](../contracts/style-recipe-contract.md)与[影响合同](../contracts/revision-impact-contract.md)。

## 尚未实现，不能宣称已完成

- 自动理解素材并推荐最适合的完整叙事风格；真实同内容风格盲评。
- 输入自然语言自动生成可靠局部修改；跨镜头因果与中文语义理解的实效提升。
- 逐镜头局部渲染、自动无监督恢复失败任务、模型/提示版本成本核算（候选整段复用及显式队列恢复已实现）。
- 中文字幕语义重排、完整听感自动验收、无损全编辑器工程往返。

真实素材与宿主的当前覆盖见下文。后续仍须逐项完善内容证据、场景安全区、语义及真实用户验收，不借用合成测试替代。

## 第二切片：对比预览与现有队列恢复

新增 [style-recipe-preview](../atomic/style-recipe-preview/SKILL.md)，把同一 Work 基础上的两到四份明确包装配方串成可观看的小样与参数对照。所有候选继续沿用同一内容，且不改变正式 Work 头；不能把字幕或音量差异称为叙事机制已验证。

候选预览的恢复与复用扩展现有 work-batch-render 请求和回执验证，不另建缓存数据库。候选 SHA、基础版本、输出摘要、实际源消费绑定与执行环境均需核验。失败或取消保留既有尝试供诊断，不覆盖原素材；只有校验通过的成功产物才可复用。它仍不等于逐镜头增量渲染，也不自动采纳旧版本候选。


## 真实素材驱动的第三切片

用户授权使用网上合法公开素材后，本轮下载原媒体并保留来源/许可/摘要，不把媒体二进制入仓，也没有向外上传私有数据。

- **叙事**：Tears of Steel 原片 30–36 秒，双候选预览→包装提交→恢复原参数→过期版本拒绝完成。
- **访谈/软件演示**：真实原 WebM 分别被视频时钟/音频连续性校验拒绝；显式 30fps、48kHz PCM 派生后完成相同链路。转换可能复制/丢帧、补音，不是无损或原格式直通通过。访谈 45–51 秒为植物 B-roll，另用 100–106 秒讲话人近景验证。
- 四个短窗共十二个输出完整解码，候选与恢复输出的解码 PCM 摘要相同。音频数值一致不是听检。演示字幕明确为测试标注，不冒充原声转写。
- **真实中文语音**：Google FLEURS 三份录音参考文本覆盖否定词、数字和 WiFi。发现并修复 SRT 隐式 ASS 画布使默认字幕巨大溢出的缺陷；修复后实际抽帧文字完整，原 WAV 摘要、字幕文字及时间范围保持。背景为合成色板，时间为比例估算，未做 ASR、听审或真实对齐。
- **真实编辑器**：[实验 Blender 导入器](editor-adapters/blender-cut-import.md)支持严格受限的原视频/原声硬切。Blender 4.3.2 实际导入、剪点调整、保存重开与渲染已验证；不含字幕、GUI、逆向读回或一般编辑器互通承诺。

实际目视仍发现软件演示较大/较高字幕遮住下方编辑区，当前通用配方不能认定场景安全区适配合格。后续优先做显式保护区及实际渲染验证，不以“参数合法”代替画面合格。本方案尚未整体验收完成。

## 第四切片：真实失败驱动的受限修复

- [显式媒体规范化](explicit-media-normalization.md)：新增 opt-in 工具，不是渲染失败后的自动降级。保留原片，按同一源时间原点转换，记录源/派生摘要、命令、工具与可能补音/丢补帧；正负120ms及前导静音夹具验证声画事件位置。成功回执是唯一提交标志，失败诊断不冒充可消费产物。
- [字幕覆盖合同](../contracts/style-recipe-contract.md#可选真实字幕覆盖检查)：显式保护区域，加实际libass字形/描边alpha与扩大画布验证，无法证明时拒绝。无约束旧调用保持UNKNOWN，不暗示自动识别UI。
- 原960×540教程画面几乎满屏UI；12px细字虽能避开狭窄区域，实看仍不够可读，保留失败。评估副本明确改用960×636画布，完整源画面居中在y48–588，24px字幕在独立下带，抽帧可辨且不遮UI。它是可选的新画布方案，不是偷偷改原Work，也不保证所有发布平台适配。
- [效率基线工具](local-benchmark.md)分别提供历史证据统计和受控冷/复用测量。历史记录没有时间就标未记录，不从mtime猜；一次测量不外推生产费用或人工节省。
- [完整验收矩阵](product-acceptance-matrix-20261112.md)逐条保留九格真实案例、首批风格卡、创作简报/参考采纳、语义/召回、真实看听、偏好与成本的未完成项。工程机制通过不等于整体产品方案已验收。


## 第五切片：保文字幕入口与显式信息顺序机制

- [字幕兼容导入](../workflows/raven-film-recap/douyin-film-recap/docs/subtitle-compatibility-import.md)修复真实官方中文字幕77条被静默读成0条的入口缺陷。默认损坏时轴/游离正文等明确拒绝；显式兼容策略保留全部正文和原时轴，整数序号歧义需声明策略。原始字节与摘要绑定、原文件不变，规范派生仍过未放宽的严格QC；独占原子发布避免部分文件冒充产物。官方英文76条、中文77条逐项结构/全文比对，中文43秒起点没有套英文42.2秒。不是翻译或听审通过。
- [result-preview-compile](../atomic/result-preview-compile/SKILL.md)复用既有教程编译器和Work修订合同，将明确的后段源窗前置为带标签的预览，随后保留完整原流程。源重复、所有旧片段位移及输出/字幕/备注变更均需显式范围；未支持的持久证据保护、独立音轨、视觉层保留并拒绝，不建议撤保护。
- 真实wikEd试验是原片60–64秒预览 + 完整24–64秒流程，共44秒；查看2/5/42秒帧确认后段预览→回到原流程→原后段，原Work头不变。48kHz单声道投影对齐比较前2,112,000样本相关0.99992367；AAC解码另有512样本尾padding，不能说PCM相同或听感已通过。
- 这是原创 consequence-first 机制卡的有限执行实验，不是独立参考视频迁移、因果证明或整张风格卡效果认证，亦不凑作首批6–10卡全部通过。后续仍按完整验收矩阵逐项完成。

## 第六切片：简报交接与受保护结果预览

- [creation-brief-prepare](../atomic/creation-brief-prepare/SKILL.md)保留用户原话、字段来源、当前Work与缺项，仅准备既有字幕包装或教程校验请求。Agent仍负责语义判断；原话切片不是授权认证。PLAN/ANALYZE只交草案，不执行；无词对齐/叙事决定时明确缺项，不生成虚假的精剪请求。
- 两条公开真实素材下游已实际执行：40秒软件流程的声明时序检查、6秒讲话人双字幕包装渲染；原Work不变。推进隔离测试Work后旧简报拒绝，旧字幕预览请求也拒绝。教程下游本身没有Work CAS，所以执行前额外读取头，不把旧计划成功当作新作品修改。
- [持久证据保护共存](result-preview-protection-20261112.md)不再一律拒绝受保护的结果预览：原声明、源窗、carrier、依赖与原镜头全部保留，仅在显式映射范围内验证精确位移。真实44秒候选所有原证据恰后移4秒，预览不注册为原证据；完整解码帧与先前同内容输出一致，不是听审或因果验收。
- [九格真实案例候选](evaluation-cases-20261112.md)覆盖人物立场、语音否定/数字、教程前置等实际候选范围，绑定来源及未知；结构/文件身份/既有恢复证据通过，不将九格都填语义通过。
- [首批九卡分层](style-validation-cohort-20261112.md)逐张绑定卡文本与确有的机制证据，不改580卡状态，不把字幕参数变化算作完整叙事风格。
- 三类公开6秒短窗各3次新batch冷渲染/复用共9组，产物身份全部复核。具体观测见[效率基线](local-benchmark.md)；并行测试负载未控制，不给通用提速、生产费用或人工节时承诺。
