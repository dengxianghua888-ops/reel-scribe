# 第九切片：明确反馈修正、结果先行桥接与后级呈现复用

延续上一批，不将技术机制完成当作完整产品效果验收。

## 明确问题，才生成下一轮假设

推荐器新增一轮 `refine`。它绑定原推荐、反馈、观察文件及当前 Work；只有明确的太小、太大、挡住界面或保留当前尺寸才提出有方向的字号比较。笼统不喜欢、未知、矛盾方向、不一致锚点不会被擅自解读为“字体应放大”。

候选保留原尺寸对照，并维持原字号上下限、画布上限、内容与时间范围。不因触顶而放宽约束。观察文件摘要只证明身份，不证明看过、判断正确或用户同意；反馈驱动的是下一轮待预览假设，不是自动采纳、训练或审美结论。首版只支持一轮，继续细化必须明确报不支持，不能无限递归追溯文件。

## 参考顺序与目标证据分开

参考迁移新增 `narrative/result-first`，仅允许软件教程的 `adapt`。必须提供按时间排序的结果预览→过程观察区间及逐段证据、未知项；一个时间卡静帧不能被当作叙事顺序实证。

目标仍须明确源窗、步骤证据、全部原片段位移及范围。准备器复用已有 `result-preview-compile` 临时编译校验，不复制另一套保护算法；临时候选不发布、不渲染、不提交 Work。最终请求实际使用前仍需新读版本及原始证据。原流程、固定“后段预览/非当前成功”标签及已有持久保护不可撤销；预览不是新的成功证据，参考顺序不证明目标因果。

本轮独立公开影片/教程的“结果先行”效果实证尚未建立。已有自制44秒机制示范可作真实媒体技术 fixture，但不得包装成独立参考研究发现。

## 基础时间线复用扩大，不复用最终效果

同batch、同Work版本、完整plan相同的候选，除字幕呈现外，可在独立音轨仅gain或视觉层仅rect/opacity/z变化时复用已验证基础timeline。音轨/视觉层ID、源身份、窗口、锚点、时序及其他字段保持相同，未知或类型不同的差异不命中。不支持增删层、改速、替换素材或跨batch缓存。

音轨混合、视觉合成、字幕及最终QC仍各自执行；各候选全部资源仍通过源消费与末次校验。保留完整donor依赖验证，不因某资源“只影响后级”就忽略其损坏。范围仍是基础时间线，不是shot级或后级缓存，不继承旧QA。

## 本轮实际试验与保留缺口

- **反馈修正链**：许可历史教程短窗，基于实际抽帧的agent-observation `prefer-current`保留34px锚点，明确选择39px新假设作比较；不虚构“太小/遮挡”的原故障。两候选实际渲染、完整解码，PCM相同、原Work不变。新假设是否更好仍需实际评价，不能由渲染成功推出。
- **叙事桥接**：参考为既有自制44秒“后段预览→回到原流程”机制fixture，实际只观察2/5/42秒帧，非独立开源参考实证。目标为原40秒教程受保护副本，临时校验→正式编译→44秒预览实际执行；保护声明和全部原clips/sources精确保留，两个Work头不变，完整解码通过。输出SHA与此前同机制样片相同，说明桥接一致，不是新的创造性效果提升。
- **真实音轨增益共享**：教程2秒加FLEURS许可录音前2秒，候选仅-18/-6dB不同。timeline执行1次、audio-mix与QC各2次；各自与独立不共享基线的RGB/PCM摘要相同，两增益版本声音数据有差异。19份回执运行时摘要匹配冻结代码。此为数字处理试验，录音不是完整句子，不能作为否定保真或警告交付，也未听审。
- **真实视觉层缺口**：现有教程派生源标记color_space=bt470bg、range=tv，未提供transfer/primaries；原电影也无完整色彩标记。以bt709声明初始化实际触发`OVERLAY_COLOR_CONFLICT: color_space`，未绕过或重标源文件。没有把未经证明的色彩解释当真实色彩保真。视觉增量仅有已知bt709合成输入的工程正负例，真实素材视觉层验收仍需可信源色彩定义。
- **定向及独立复核**：推荐32项、参考38项、共享31项通过；独立16项身份/字节/顺序负例，以及共享20边界、9独立负例、3组FFmpeg对照通过。完整冻结快照回归与远端CI以最终提交记录为准。
