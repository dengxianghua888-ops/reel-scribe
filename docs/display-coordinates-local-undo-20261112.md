# 显式展示坐标与局部呈现撤销

## 展示坐标不是源像素，也不是自动识别

`screen-focus`保留原有源像素请求；可选`coordinate_space`声明完整源画面的等比展示尺寸及预期真实源尺寸。实际probe核源尺寸与旋转/SAR，Fraction精确转换crop、高亮框和线宽，非整数映射、非等比、越界与奇数源裁切继续拒绝，不猜偏移、黑边、旋转或取整。输出像素尺寸不随展示坐标解释改变。

`focus-map`保留原源坐标语义，另记输入声明/矩形及精确比例。结果回读核实际输出宽高、SAR及音轨codec/sample-rate/channels，末次检查源SHA。音轨元数据相同不是波形相同，更不证明听感。声明截图来自完整等比画面不等于系统认证其来源；需要实际抽帧确认选区。

本次不改默认MP4，不添加容器选择或隐式AAC转码。第十批已更正“PCM必须转AAC”的错误推断，当前FFmpeg实测可以直接复制。视频仍重编码，不承诺和原源逐像素无损。

## 只撤销某次指定字段，不整版回退

`work-version/prepare-local-undo`从权威Work版本库读取某次普通commit的before/after与当前版本，限定字幕font_size/margin_v/color_rgb或既存独立音轨gain_db。必须显式给当前版本、undo_sequence、结构化字段选择及原有完整scope。

当前值仍等于该次after时恢复before；已等于before是NO_OP；第三种值表示后来同字段已修改，拒绝覆盖。历史文档摘要/版本/parent链、字段存在性、音轨非gain身份及锚点源身份均验证。只以当前文档为底稿，未选的字幕、音轨、镜头、备注与保护保持，继续原revision_diff/范围校验。只准备标准候选，不改Work、不渲染；采用仍需既有commit的当前版本/CAS。NO_OP不输出candidate。

**明确限制：**实际需要修改且当前存在任何style_bindings时本入口保守拒绝，避免保留失真的配方参数或旧约束。不能清空绑定绕过；有绑定作品应继续用原有显式配方/范围路径处理并重验。本版不支持字体、增删轨、剪辑/叙事撤销，也不自动恢复变化后的音轨身份。未选的后续时间编辑可以保留，不意味着音轨输出位置被冻结。author、scope及历史字段只是记录/机制，不自动认证真人授权或原意。

## 本批真实素材技术验收

素材沿用Nikkimaria的历史[WikEdtutorial1](https://commons.wikimedia.org/w/index.php?title=File:WikEdtutorial1.webm&oldid=1131672871)，CC BY-SA3.0。截取、归一化、字幕/框选及重编码是评估改编，不暗示作者背书；视频未提交源码，交付派生片应保留署名、来源、改动和同许可。

### 显示选区与源像素相符

原约25–28秒窗口，声明960×540展示对应1920×1080完整源。display路径和手写源像素路径实际渲染，全RGB与PCM摘要/字节数分别完全相同，输出文件也同SHA256 `83fd0c4647adb8662acba5950d1dfd9c6735394219320f3deef5d805d023806f`。PCM与本次输入相同，无AAC转码；视频3秒，复制音频包尾为3.012312秒，不宣称两流均精确3秒。2秒实际帧可见library_name/image/location与橙框。

错预期源尺寸、非整数源坐标均拒绝且无focused.mp4；4份回执与冻结44个运行时文件一致。原源未变，未访问Work。只核这一短窗，固定裁切丢失周边导航，不能推广到后段Preferences操作；未连续看听或认证教学质量。

### 撤销字号，保留后来的音量和备注

独立新建、明确无style_bindings的6秒Work：普通commit字号24→28；后续普通commit音轨增益-18→-12及备注；只准备撤销前次字号，候选恢复24但保持当前plan/captions/audio_tracks/notes等。准备过程不改当前Work，原已有Work与源也未改。实际当前/候选渲染完整解码通过，PCM两者相同；这不是与最初音量或原始源音频相同。

初版、当前、撤销候选均实际渲染；2秒帧对照显示相同编辑界面及示范字幕，当前字号较大，撤销后回到初版字号，字幕处于独立黑带。这是局部参数恢复，不是整版恢复或审美优劣。同字段后来再改、音轨删除、音轨时间偏移变化三个隔离负例分别报冲突、字段缺失及身份冲突，不生成覆盖候选。26份回执与冻结44个运行时文件一致。重复同源音轨仅为增益管线fixture，不是创意配乐。未作完整听审、语义验收或真实用户手改认证；有recipe绑定作品的撤销仍不受此入口支持。
