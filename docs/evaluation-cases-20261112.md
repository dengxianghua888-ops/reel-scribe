按叙事影视、真实语音、软件演示三类，每类正常/复杂/易误判各一格。
每格绑定真实媒体 SHA-256、原时间窗、文本/观察依据、依赖和未知。
有意复用部分时间窗以检验不同依赖，不能宣传为九段独立充分素材覆盖。

## 依据边界

影视依据是官方英/中字幕、先前32s静帧记录，以及本批实际查看的原片43s帧，非听译审查。
两种字幕的条数/时轴不同仍需保留，但这种格式差异**不算复杂语义案例**。
FLEURS是独立真实朗读录音，不是自然口误、多take或人物视频。
初版软件依据仅27s和80s静帧，两个旧窗及当时未知保留在manifest的history。
第十一批补充21张逐帧查看的静帧（详见下节），仍没有连续观看、听审或保存成功证明。

## 已落实的可执行核验

```sh
python scripts/validate_evaluation_cases.py \
  examples/evaluation-cases/nine-cases.json --asset-root /path/to/authorized-cloud-assets
```

工具只读，检查9格完整性、窗口/身份/依赖声明、媒体及证据SHA。
它还实际读取已存在的真实影视Work回执，复核包装变更未动
`plan/captions/audio_tracks/notes`，还原文档完全一致且版本向前，过期CAS被拒绝。
这是**复核已有哈希绑定技术证据**，不是本轮重渲染或语义验收。
缺媒体/回执返回NOT_RUN及退出码2；哈希不符、窗口错误或保护字段变更直接失败。
无素材根时仅校验结构，退出码2，不能冒充本地验收通过。

云端本轮结果：9格结构与全部本地源/证据身份校验通过；既有Work保护与恢复回执
一致性核验通过；语义/听审仍NOT_RUN。媒体不入仓，工具不下载素材、不调用模型。

## 必须保留的失败/未知

- 原教程WebM `SOURCE_AUDIO_DISCONTINUOUS` 拒绝回执保留；规范化派生通过不等于原输入通过。
- 先前教程短窗字幕遮挡控件的静帧发现保留；这是视觉问题，不算复杂语义证据。
- FLEURS字幕旧版默认样式巨大裁切的结果保留；它对应历史提交，不代表后续已修版本仍失败。
- 既有Work的过期版本拒绝是预期负例，不能计作可用性故障，也不能删除以制造全绿。
- 真实内容理解、ASR、翻译、动作顺序、人脸/控件动态安全区、原生编辑器、用户偏好均未因此关闭。

## 第十批增量：原片上下文与明确负例

实际查看原片43秒提取帧，画面明确显示 **40 YEARS LATER**，背景为未来城市。
官方英文字幕42.2–45秒同条合并标题与“We’re done”，不能据此把该时段全当桥上连续对话。
这是一帧直接视觉观察，不确定精确切镜起点，也不判断对白是否跨画面延续。
新增图片及观察记录身份已绑定manifest，原媒体与派生图片均不随源码发布。

在最终冻结运行时下，新建独立Work使用原片25–45秒，声明依据官方字幕提出的
question→denial→admission源窗依赖。完整源窗实际渲染并全流解码；三个故意破坏候选分别检查：
截掉后续承认的覆盖（`CARRIER_DOES_NOT_COVER_UNIT`）、
把回应放到否认之前（`PREREQUISITE_NOT_BEFORE_UNIT`）、
删除必保声明（`WORK_PROTECTION_DECLARATION_FROZEN`），均按预期拒绝。
保护规则检验的是调用者显式给出的源范围和先后条件，**不是程序自动识别语义矛盾**。
字幕文本中的问号、先否认后承认可按官方文本核对；实际说话人、声学词边界和听感未核。

最终回执与产物在云端 `reel-ninegrid-source-review-stage10-final`，探索目录单独保留。
本批只推进影视格的文本来源、单帧事实和声明依赖保护，不把一段素材重复测试宣传为九格全通过。
语义验收与听审仍为NOT_RUN，无词级金标。FFmpeg/ffprobe仅用于技术解码/取帧；
没有安装ASR、下载模型或调用付费服务，也没有以波形或字幕注释代替听审。
