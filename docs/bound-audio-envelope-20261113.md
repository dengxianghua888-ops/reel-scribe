# 已绑定呈现配方的独立音轨淡变与撤销

## 实际能力

既有唯一全局编译配方现在可明确加入 `audio_envelope`，并声明 `audio-track-envelope`。保留原字幕默认、逐cue覆盖、音轨映射和布局约束，不删除绑定来绕过验证。原包络结构、精确采样时钟、源身份/源窗、保护单元及 scope/CAS 沿用现有机制。

逐cue编辑可原值携带音轨映射；音轨单独编辑也可原值携带既有cue映射，不强迫假选一个字幕。局部撤销须明确派生配方，只撤选中包络；原先无包络时恢复缺省并移除该映射，保留后改的未映射gain和手工备注。空派生配方仍拒绝。

绑定摘要与实际值检查只证明声明自洽，不证明作者身份或请求授权。未知、多绑定、错误摘要、丢失原参数/布局、缺资源/null污染、非法数字、越界范围继续拒绝。没有自动配乐、ducking、自动偏好学习或整卡风格认证。

## 独立评审发现与修正

本批发布前独立审查复现三项问题并修正：

1. 已有逐cue覆盖时只改音轨淡变被错误要求选择字幕；现允许原值携带，偷偷改cue仍拒绝。
2. 手造且重算摘要的绑定可用不存在音轨的null增益伪装自洽；现按编译器可产生的结构检查资源、字段、类型和范围，不仅比较摘要。
3. 合法整数增益经编译器转为浮点后被严格JSON比较误拒；仅gain经严格数值校验后比较值，其他声明保持严格，不改配方原文或摘要掩盖差异。

入口形状修复前定向109项通过；独立8探针通过（包括bool、NaN、Inf拒绝），对应测试前后runtime摘要一致。全量随后发现空binding触发KeyError而非明确拒绝；补齐绑定/参数形状预检及无实际包络时的防御式检查，并重新进行最终归档全量和实媒验证。旧109项不代替修后全量结果。形状修复后的最终67项定向通过，另13项独立回归通过并核对源码摘要不变；两组有重叠不累加。作者35项与这些测试有重叠，不累加为独立总数。旧复现脚本的“passed”表示成功复现缺陷，不是产品当时通过。

## 真实许可素材验证

沿用已下载WikEd六秒规范化教程（CC BY-SA 3.0）与Tim Smit讲话人六秒规范化片段（CC BY 3.0）。本次独立测试轨取讲话源0.5–4.5秒、落在输出1秒、-18dB，只为测试数值路径，并非适合教程的配乐推荐。来源、原许可及改编说明见[素材记录](product-iteration-20261112.md)。未新增下载、未提交媒体、未外传私有数据。

最终第四轮使用已有全局字幕及单cue覆盖的隔离Work：绑定 → tri/qsin两份明确配方 → 冷/共享预览 → 采用tri → 后改-12dB与备注 → 仅撤包络派生新配方 → 实际渲染。预览原头不变；测试历史的采用/后改/撤销均为明确的隔离测试操作，不声称所有测试头不变。

- 两种候选各自冷/共享完整RGB与PCM相同；qsin确有基础时间线donor，各自混音、字幕及QC仍执行。
- 独立手写FFmpeg链不调用产品包络/混音函数；两种实际包络输出与控制组完整RGB/PCM一致。
- 撤销保留后改gain和备注，实际输出与独立手工预期文档渲染声画一致。
- 43份正例回执与46个runtime文件身份核验；另6个真实源负例拒绝：缺audio/style范围、错误配方摘要、丢旧字幕映射、已失真绑定、删除实际包络却保留声明。失败不产生candidate且测试当前头不变。
- 三项源输入SHA保持；既有源窗、片段、字幕正文/时轴不变。

首轮及第三轮旧码实媒通过保留为历史，不替代最终第四轮。第二轮脚本初始化cue绑定时遗漏明确caption scope，正确拒绝，已补调用范围；不记为产品缺陷或绕过授权。旧测试夹具目录冲突、一次并发回归PARTIAL及后续单测复跑分别保留，不改写原结果。
