# 独立音轨首尾淡变与局部撤销

## 实现范围

Work 独立音轨新增可选 `envelope`：48kHz 样本数声明的淡入/淡出，支持 `tri`、`qsin`。原 source 身份、源窗、锚点和位置继续保留；不是先生成新声源来替换原身份。省略 envelope 保留旧音频路径。独立轨淡变不改变原视频音轨的 `base_gain_windows` 阶跃行为，不提供自动配乐、自动 ducking、响度优化或听感认证。

入出点与输出位置必须采样对齐，淡入加淡出不能超过源窗。验证完整实际解码 f32 样本数，不通过 padding 弥补不完整音频。Work 输出起点用原始帧时钟加 offset 计算；转换到 JSON float 时仅容许最多 2 ULP 且不超过百万分之一采样的数值表达误差，非任意取整。真实五帧/25fps + 0.1s 用例曾被浮点相加误拒，本轮独立评审发现并修正；半采样和可分辨的偏移仍拒绝。

- 持久保护单元若与该轨淡变衰减区间相交，拒绝。不得删除保护使请求通过。
- 仍须明确 audio_ids 范围、当前 Work 版本和原有约束。已有 style binding 暂不支持 envelope，不移除绑定绕过。
- prepare-local-undo 可只撤 envelope，保留后改 gain 和 notes；同字段冲突或轨道/源窗/锚点身份变化拒绝，prepare 不提交。
- 批内仅共享基础时间线，混音、字幕和 QC 各自执行。源窗、源身份或位置变化仍不能走该复用。

## 真实素材实验与限制

使用既有许可 WikEd 六秒规范化教程（CC BY-SA 3.0），独立技术测试轨使用 Tim Smit 访谈（CC BY 3.0）0.5–4.5秒，输出 offset 1秒、-18dB。它不是适合教程的配乐推荐。源资料与改编说明沿用[产品迭代素材来源](product-iteration-20261112.md)，没有媒体提交到仓库，也不外传私有材料。

两种明确包络分别进行冷渲染和同批共享预览；独立 FFmpeg 命令构造对照，不调用产品包络或混音函数来生成期望结果。比较完整 RGB/PCM 而非只抽样峰值，并检查实际 timeline donor 与每个 job 的混音、QC 回执。撤销另建隔离 Work：先提交 envelope，再提交音量和手工备注，只撤 envelope，实际输出与手工预期文档对照。测试 Work 的预定提交不是“所有头都未变”；预览 Work 与源素材另行验证未变。

此前真实 no-scope 负例脚本在已经撤销后的 Work 上重试，正确返回 NO_OP，脚本断言因此中断。该旧结果不算越权拒绝通过，也不算产品越权缺陷。后续补测在尚未撤销的隔离历史中分别验证缺 audio scope 与后改源窗冲突，保留失败时 Work 不变。

本轮完整连续听审、语言内容正确性、曲线听感、主观音乐适配、风格整卡和真实用户验收仍未运行。RGB/PCM 对照仅证明技术执行一致，不证明声音好听或语义完整。现有九卡 `whole-style-validated` 仍为 0。

修复前回执与修复后回执分别保留，前者不冒充最终 runtime 结果。测试包含参数类型、曲线/范围、采样边界、完整解码覆盖、持久保护、授权范围、版本与三方撤销、旧路径对照和真实 FFmpeg 回归。最终代码的完整测试、真实素材重跑及独立身份复核结果随本批完成报告提供；未完成的检验不计为通过。PR 保持 Draft，不合并、不部署、不更新未获确认的 PR 描述。

### 最终 runtime 独立复核与真实实验

最终 runtime 的55项定向/独立回归全部通过（23.06秒）。独立真实第四版重跑：46份正例回执、9份负例回执完整匹配46个 runtime 文件；3项输入保持原SHA。tri/qsin各自冷/共享完整RGB与PCM一致，视频RGB等baseline，两种PCM不同。独立FFmpeg控制组的完整MP4及解码声画相等；qsin donor与5项基础时间线产物身份重新核验，各自混音/QC存在。局部撤销仅移除envelope，保留后改-12dB及手工备注，输出等手工预期对照。缺audio范围与后改源窗负例均拒绝且不改测试Work。

修复前两版媒体证据不代替以上最终同码重跑。两个已复现误拒（锚点相加与端点相减消差）均有实际FFmpeg回归。无envelope旧路径另与真正`df37055`归档对照，输出完整文件SHA一致。这里只认证已声明短窗、精确参数与所用媒体格式，不外推其他音轨、音乐风格、真实听审或语义效果。
