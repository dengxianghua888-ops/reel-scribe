# 第八切片：解释型候选、逐项参考迁移与中间结果复用

本文件描述候选分支的受限实现，不代表默认分支已发布，也不是整套产品方案验收。

## 从明确创作目标到可比较候选

`creation-recommendation` 根据明确场景、目标、调用方能力声明、字号范围与当前 Work 提出候选。字幕建议只改变字号，保留文本、时序、声音、镜头和布局其他字段；更大字号是待验证假设，可能换行或遮挡，并不天然更好。场景卡只是已绑定的规划上下文，不宣称它的完整叙事风格已经执行。

推荐、显式选择、下游预览、反馈分别留记录。选择时重新生成并比较原推荐，检查 Work、卡片和目录身份；反馈中的可读性、遮挡、风格适配等是未认证的归因声明，不变成用户授权、自动采用或训练真值。已有明确教程步骤可推荐既有编译器检查；口播缺对齐或剪辑决定时列缺项，不自动猜删词。叙事内容判断仍由运行 Agent 在真实证据上完成。

详见[推荐合同](../contracts/creation-recommendation-contract.md)。

## 参考机制不是整体复制

`reference-transfer-prepare` 绑定参考媒体和观察证据，分别记录叙事/视听轴以及 adopt、adapt、omit 与理由。当前可执行交接只限字幕呈现。参考叙事文案、因果顺序、声效等不能随字幕参数夹带进入目标作品，未观察项不能被采纳。

观察区间和文件摘要只是来源身份，不证明观察者真的看过，更不认证完整看听或效果。实际使用必须保留具体可见事实和未知，并独立验收目标预览。准备器不运行渲染，不改 Work，不把参考媒体加入产物。

详见[参考迁移合同](../contracts/reference-transfer-contract.md)。

## 增量能力的边界

本批选取同一 batch 内、同基底作品的字幕包装候选共享基础时间线，而不是直接拆分镜头缓存。拆镜头会涉及源窗量化、声音拼接和编码边界，不应以性能目标绕过等价性证明。

共享只允许完整内容相同、无独立音频或视觉层的受限情况；源、后端、工具、运行时代码、成功回执与实际产物须重新验证。接收候选仍独立烧录字幕、检查结果，并保留复用来源；不能复制别人的成功回执冒充本次执行，也不继承旧 QA。

详见[共享时间线合同](../contracts/shared-timeline-contract.md)。具体测试与真实输入证据在最终提交时追加；代码存在不等于测试通过。

## 独立参考观察及真实失败保留

实际查看了 Tears of Steel 30、36、43 秒以及历史 wikEd 教程约27.003、80.003秒的五个静帧，没有连续看听。43秒 `40 YEARS LATER` 是原片叙事时间卡，不是字幕文本；仅借浅色高对比文字呈现假设，不复制文案、字体身份或中央位置。软件参考底部 Save/Preview/Changes 按钮是操作证据，不能被贴底文字覆盖。

受限迁移目标使用既有公开教程25–31秒规范化短窗，保留既有“演示标注”而非假造原声转写。原26px/margin20、34px/margin42配方加独立安全字幕带约束后被实际拒绝 `LAYOUT_GLYPHS_OUTSIDE_DECLARED_BAND`；保留失败，显式改用24px/margin8及白/暖白两变体，非自动绕过。源码并行改动曾触发 `BATCH_RECEIPT_ENVIRONMENT_CHANGED`，保留为环境一致性拒绝，不归因媒体损坏；最终版本另建批次重验。

电影素材为 Blender Foundation《Tears of Steel》，CC BY 3.0，来源 https://mango.blender.org/sharing/ 及 https://download.blender.org/demo/movies/ToS/tears_of_steel_720p.mov 。目标教程为 Nikkimaria《WikEdtutorial1》，CC BY-SA 3.0，固定页面 https://commons.wikimedia.org/w/index.php?title=File:WikEdtutorial1.webm&oldid=1131672871 。引用观察不把参考影片画面引入目标产物；实际改编教程另受同许可要求。原素材、静帧与运行产物未加入代码仓库。

## 验证范围

- 新共享缓存13项定向测试通过：有声合成输入两候选只执行一次基础 timeline，字幕和QC各两次；与独立无复用渲染的解码RGB和f32 PCM逐字节相同。不同源消费模式的独立负例不共享，异常后上下文恢复。完整输入/工具/代码/回执身份规则保持，不宣称通用提速百分比。
- 推荐器17项测试及独立10项发布竞态/同次字节负例通过；参考准备器及跨操作交接23项通过。这里的数字是限定机制覆盖，不证明真实推荐质量或整卡风格。
- 完整回归、最终SHA与远端CI由PR验收记录绑定。前版影片子目录未改时只复用明确同代码的历史结果，不能把旧CI说成本批CI。

最终冻结运行已完成两条真实链：

1. **推荐链**：公开历史软件教程6秒短窗，实际建议34px/29px/24px（排名解释为待验证假设），显式选择前两项→渲染→完整解码→抽帧→agent-observation反馈记录。两预览解码PCM摘要相同；原Work未修改。在隔离测试Work仅增加备注后，旧版反馈被拒；篡改报告后即使重新给文件SHA也被确定性重建拒绝。反馈不更新排名，不是自适应学习闭环或用户偏好认证。
2. **参考链**：上述单帧文字机制→明确adapt/omit矩阵→安全外置字幕带两真实预览。两输出完整解码通过，实查输出2秒帧文字完整且不遮教程；原Work及隔离Work、源身份和候选的plan/captions/audio/notes不变，参考电影不进入产物。此片段是教程25–31秒，不冒充80秒Save按钮场景已验收。最终运行时文件摘要与本批代码一致。

两链均未连续看听、未取得手机端可读性/陌生用户教学任务验收，也没有把演示标注说成原声字幕。对外分享教程改编产物须保留上述署名、变更说明及CC BY-SA 3.0。
