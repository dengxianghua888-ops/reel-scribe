# 绑定作品独立音轨淡变：设计与验收计划

限定唯一 `*` 编译配方，可重建其摘要并逐项核对当前呈现映射。新增显式 `audio_envelope` 参数和 `audio-track-envelope` 能力，不清除风格绑定，不认证整卡风格。原有字幕、音量、局部覆盖、布局约束必须保留；未授权变化仍由原 scope/CAS 拒绝。包络使用现有样本校验及保护规则。

局部撤销派生新配方，仅撤指定 envelope；缺省表示恢复无包络并删除对应映射，保留其它参数及后改非映射 gain/notes。空派生配方仍拒绝。手写、多绑定、摘要错误、映射失真继续拒绝。

验收：编译/预览/撤销正例；遗漏原映射或布局、未授权音轨/绑定、受保护衰减、篡改摘要、后改同字段冲突负例；旧调用回归。真实素材声画对照由独立执行记录，听审与完整风格验收不由单元测试替代。

## 独立评审修正

- 已有 cue override 绑定允许音频-only 请求原值携带，选中 cue 的呈现改动也能保留包络；两个方向均不顺带扩大修改范围。
- 最后一条实际包络被删除而绑定仍声明包络时拒绝，不能只在音轨含字段时验证。
- 重算摘要不能使缺失轨道/字幕或 null、未知映射键合法；验证参数合法形态与当前对象。摘要仅证明一致性，不认证作者、调用来源或批准。
- 编译器会将 gain 整数归一为浮点；绑定一致性只对 gain 严格校验类型/范围后数值比较，不因 -6 与 -6.0 误拒，也不放宽 bool/null。其他字段和原/新配方声明仍保持严格比较。

测试历史保留：新用例前两轮输出目录复用及预期错误字符串错误已修；旧回归组合曾出现单个共享渲染 PARTIAL（当时测试与源码修改重叠），冻结后该实际渲染用例独立重跑通过，不能倒改原失败。最终集成及真实素材证据由协调者绑定最终源码另记。
