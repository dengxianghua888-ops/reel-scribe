# 逐条字幕呈现（第十四切片）

本批继续完整方案的局部修改能力，不改字幕正文、时轴或字体，不将机制验证等同整卡风格与完整作品验收。实现与证据按本文件所在提交追踪。

## 用户价值与边界

明确“只强调这一句”可对已有字幕 ID 指定 `style_override`，仅支持 `font_size`、`color_rgb`、`margin_v`。未列字段继承当前全局样式；不自动挑选重点，不从语义推断颜色/字号，不接受 ASS 注入。不存在覆盖时不加入空对象，保留旧请求行为。

配方通过 `parameters.caption_overrides` 显式指向字幕 ID，不能把正文/时间改动包装成样式操作；采用仍走现有范围保护、版本校验与候选流程。已有兼容配方的非目标映射与约束不能静默丢弃。局部样式与全局样式的有效组合参与布局检查。原配方有显式布局约束时保留并检查整个候选；无约束时仍报告 UNKNOWN，不以技术编译成功填为视觉通过。首版局部配方只改选定 cue，携带的全局/音量映射仅用于保留旧声明，不允许同时借机改动它们；已有 cue 配方绑定的 global-only 配方替换明确拒绝，避免默默丢弃局部绑定。

删除局部字段的意义是恢复继承当前全局，不保证恢复历史外观。如果后来全局字号改变，撤销旧局部字号应明确显示新的有效字号，不能报告旧值仍在生效。冲突、多义绑定、无法安全表达的配方派生仍应拒绝。

作者四组专用测试共 66 项，加独立审查 15 项反例合计 81 项通过、无失败/跳过。独立审查未发现阻断；唯一警告为跨目录 pytest 缓存不可写，不涉及产品行为。最终精确提交的完整回归及远端 CI 另按提交身份报告，不用定向测试代替全量通过。

完整九格语义、真实中文词级边界/听审、整卡风格及用户偏好仍未完成。预览样例字幕必须明确是示范标注，不冒称真实转录。

**范围不能夸大**：基础与改后有损视频中，前后各 90 帧的帧哈希均不同。未选字幕定义与掩膜保持不代表该段重新编码后像素冻结；此能力不是局部编码。原始与改后 PCM 解码摘要一致，不能据此宣称主观听感已验收。
