# 11 对外接口：影述与剪辑 Agent、与生成侧

影述对外只有两类接口：向**剪辑 Agent**交付可执行的风格能力，与**生成侧**交换后期交接、补镜请求和生成候选。本章从影述的角度定义它们；生成侧如何产出这些文件，由其仓库自行说明。

## 一、与剪辑 Agent

对象映射与 I0–I12 接口的完整说明见 [00 顶层设计](00-top-level.md) §二。影述交付给剪辑 Agent 的内容按阶段分为三种形态：

| 阶段 | 形态 | 剪辑 Agent 怎样使用 |
|---|---|---|
| A 离线验证 | 影述本地 runtime 产出 Work 候选、渲染件与报告 | 不接入；作为效果与评测基准 |
| B 外部接入 | 外部 Agent 读取剪辑 Agent 工程（I0、I2），把风格计划翻译为编辑会话修改组（I1、I4），放入组件渲染件或实例（I5、I9），生成多风格变体（I10） | 用户在桌面里看到预演、采用、撤回 |
| C 应用内置 | 入口模板、风格包、组件库、评测 harness 作为内置资源（I8、I12） | 首页卡片、风格对照面板、属性面板 |

影述保持宿主中立：每个接口都按[能力交接合同](../../contracts/capability-handoff.md)描述“需要什么行为、怎样读回”，不假定剪辑 Agent 的内部实现。

## 二、与生成侧

### 职责

| 生成侧负责 | 影述负责 |
|---|---|
| 剧本画像、风格方向、风格圣经、镜头与提示词、生成、选片、同场粗剪 | 导入为作品、统一影调与质感、字幕与标题、混音、多版本、局部修订、发起补镜 |

### 共享的刻面词汇

生成侧的风格圣经中“后期刻面”一节直接引用影述的刻面 ID：

| 刻面 | 影述怎样用 |
|---|---|
| `look` 影调 | 以生成侧提供的风格帧为参照，用 `color-reference-fit` 拟合可编辑调色层；`color-consistency-check` 守跨镜一致 |
| `caption-style`、`design-system` | 片名、集名、字幕调性与版位 |
| `sound` | 底声、主题动机、静默点的摆放与避让 |
| `rhythm` | 预告、竖屏、解说版等改节奏版本继承 |
| `generation` | 只读；混合路线补镜时把它原样放进补镜请求 |

### 三份交换文件（Schema 在本仓库）

| 文件 | 方向 | Schema |
|---|---|---|
| `drama-post-handoff/1` | 生成侧 → 影述：入选候选、源区间、粗剪表、音轨、字幕、保护项、后期刻面、交付清单 | [post-handoff.schema.json](schemas/post-handoff.schema.json) |
| `shot-request/1` | 影述 → 生成侧：插入位置与时长、观众此刻要知道什么、前后镜状态帧、风格方向、参考角色、可用标准、预算 | [shot-request.schema.json](schemas/shot-request.schema.json) |
| `generation-return/1` | 生成侧 → 影述：候选的任务 ID、资产、实付、可用区间、缺陷时码、初选理由 | 同上文件 `$defs.generation_return` |

影述收到 `drama-post-handoff/1` 后：校验文件与字节 → 可选地用 W17 绑定 `drama-content` → 建 Work（片段、音轨、字幕、保护项）→ 按后期刻面编译候选 → 预览 → 采用。收到 `generation-return/1` 后：候选进入原作品的素材池，评审后经 `timeline-revise` 局部采用；任务超时先查原任务，`UNKNOWN` 不等于失败；生成画面在主张—证据表中标为演绎，不作事实证据。

### 版本规则

- 改 Schema 必须升主版本（如 `drama-post-handoff/2`），旧版本至少保留一个迭代周期的读取兼容。
- 生成侧引用本仓库固定提交的 Schema，不复制。

## 三、同一套素材的多次风格化

生成侧的方向决定像素；影述可以在不重新生成的前提下，为同一套候选做出多个后期版本：

| 版本 | 影述后期包（[catalog/packs.md](catalog/packs.md) S31） | 改什么 |
|---|---|---|
| 正片 | 按圣经后期刻面 | — |
| 30 秒预告 | `dp-trailer` 预告片、`dp-previously` 前情提要 | 节奏、标题字卡、音乐入点 |
| 投流切条 | `dp-hook-cut` 投流钩子切条 | 开头三秒、字幕样式、片尾引导 |
| 竖屏 | `dp-vertical` 竖屏重构 | 构图、字幕版位 |
| 解说版 | `dp-commentary` 短剧解说 | 旁白、字幕、节奏 |

边界：影述只改影调、质感、字幕、节奏、声音与包装，不改镜头内表演与画风；要改就发补镜请求。
