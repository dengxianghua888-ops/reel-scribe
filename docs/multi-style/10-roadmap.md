# 10 路线图与需要拍板的决定

> **2026 年 11 月 27 日更新：** 本章的三期排期已由 [v2 · 06 路线图](../architecture-v2/06-roadmap.md)重新安排：在第一期之前增加“测量与冻结”，第一期收成一条纵切，并给每个阶段写了放弃或转向条件。本章保留作为原始规划记录。

按 [00 顶层设计](00-top-level.md) 的收敛路径（A 离线验证 → B 外部接入剪辑 Agent → C 应用内置）排期，并与研究库[口播与带货建设判断](https://github.com/dengxianghua888-ops/editing-agent-research-library/blob/92b600d605b8bd8ed0e2c938c13561d3e66276e7/library-sync/followups/20261126-chatcut/2026-11-26-chatcut-0.10.14/%E8%87%AA%E7%A0%94%E6%98%A0%E5%B0%84/%E5%8F%A3%E6%92%AD%E4%B8%8E%E5%B8%A6%E8%B4%A7%E5%BB%BA%E8%AE%BE%E5%88%A4%E6%96%AD.md)的顺序对齐：先口播精剪与实拍单品，静态规格卡是两者共用的第一个包装模板。

## 第一期（P0，离线验证）：一条流水线、三类引擎、首批皮肤包

| 工作项 | 产出 |
|---|---|
| Schema 与目录 | 本目录 schemas 定稿 v1；`packs/`、`facets/` 目录；`build_catalog.py` 检查并入 `verify_library.py` |
| 画像 | `content-signal-extract`、`subject-safe-zone-detect`（人脸）、`material-profile-build` |
| 风格层 | `style-route` v0、`design-token-resolve`、`style-pack-compile` |
| 引擎适配 | ASS、HTML（固定无头浏览器）、FFmpeg；宿主映射规范 |
| 组件 | 第一批约 25 个（[04](04-motion-components.md) §八），全部带黄金帧与属性等价测试 |
| 风格包 | S01、S03、S04、S13、S14 五个场景的皮肤包，共约 30 个 |
| 基线与评测 | B0 检查器；B1-P 与 B1-E 复跑脚本；口播 40 条与商品 20 组评测集清单；P0 场景各 10 条优质样本卡 |
| 预览与检查 | `multi-style-preview`（文字方案、风格帧、样段）；`style-conformance-check` |

**开放评估新增**（[12](12-open-evaluation.md)）：合规门并入 B0（AIGC 显式与隐式标识、广告用语、素材权利）；中文排版门；中文口播接点真值首批 60 段与 `cut-point-snap`、`breath-policy`、`room-tone-fill`；风格指纹 L1（已有原型）与 L2；偏好事件格式与记录。

**放行条件**：五个场景各至少 2 个包过 G0–G2；合规门测试集召回 ≥ 95%、误报 ≤ 10%；排版门在抽样渲染中零违规；规格表“只改第二处”的局部修改例通过（冷开、导出复核）；每条评测素材的三个方向两两相似度低于 0.8。

## 第二期（P1，外部接入剪辑 Agent）：动起来、接进工程、能记住

| 工作项 | 产出 |
|---|---|
| 接入 | 风格计划翻译为剪辑 Agent 编辑会话的修改组（I1、I4）；组件以渲染件或宿主实例放入（I5、I9）；多风格变体（I10） |
| 引擎 | GLSL、Lottie、Motion Canvas；第二批约 40 个组件 |
| 质量 | `taste-review`、俗套检测、强度曲线检查；对 B2 的对标报告 |
| 记忆 | `style-memory`：品牌、系列、个人 |
| 扩充 | 覆盖 S01–S30 全部场景的皮肤包进入 `previewed`；设计系统 46 套全部有实现 |

**开放评估新增**：`jl-cut` 与三种遮跳方式、中文口播接点公开基准；审片—修复闭环（先建议，校准后自动）；“照着这个剪”的参照路由；声音设计规则版；预览速度与成本工程线。

**放行条件**：接点盲听可感比例 ≤ 15%；同一工程内三种风格预演、采用、撤回、冷开、导出读回一致；至少 20 个包到 `limited-trial`；系列复用试验（同系列连续 3 期）风格漂移投诉为 0。

## 第三期（P2，应用内置）：机制包与货架

| 工作项 | 产出 |
|---|---|
| 机制 | 商用许可的遮罩与跟踪方案、Three、Manim、风格迁移；20 个机制包 |
| 生成 | I11 生成任务接口上线，数字人与补镜类包可用 |
| 货架 | 入口模板目录（I8），只展示 `limited-trial` 以上的包 |
| 评测 | I12 评测 harness；全量评测集；对 B3 的差距报告 |
| 开放组合 | 临时组合包的沉淀流程 |

**开放评估新增**：自有风格奖励模型；声音设计生成版；多语种与出海版本（与生成侧合做）；C2PA 清单。

**放行条件**：机制包各自通过能力与风格验收；货架上每个包都有评测记录；首页卡片、风格对照面板、属性面板在剪辑 Agent 内可用。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 结构化过度，扼杀判断 | 语义选择与方向理由留在 runtime 槽；临时组合包保留探索空间 |
| 模型信号出错导致组件放错 | 信号带证据与置信度；低置信信号不触发高优先级组件；预览门把关 |
| 模板化导致千篇一律 | 签名手法、强度曲线、旋钮；包间相似度上限；系列内锁定、系列间鼓励探索 |
| 许可风险 | 依赖按 LICENSE 文件核对（[02](02-public-survey.md) §二）；非商业依赖只作参照；字体与音乐按哈希与许可登记 |
| 宿主差异 | 全部能力按能力交接合同映射；宿主无读回时标 `not-verifiable` |
| 风格掩盖事实错误 | 事实保护在风格层之上；主张—证据表跨包共享 |

## 需要你拍板的决定

1. **第一期五个场景**是否为 S01 知识科普、S03 数码测评、S04 教学、S13 实拍种草、S14 直播切片？
2. **HTML 渲染路线**：自研逐帧渲染（参照 HyperFrames 的 seek 协议），还是直接把 HyperFrames（Apache-2.0）作为 HTML 引擎依赖？建议先作为依赖跑通，再决定是否自研。
3. **评审资源**：目标观众 30 人与剪辑师 5 人的评审池由谁组织？没有评审池，G2 无法执行。
4. **优质样本**：P0 场景各 10 条样本由你指定创作者与作品，还是由我按入选标准先提名一版供你删改？
5. 开放评估的四项决定已记录在 [12 章 §十三](12-open-evaluation.md#十三决定记录)：接点真值只用公开语料并公开发布；合规词表留在本库版本化维护；偏好事件默认须明确同意；第二期末做一集美国英语译配试点。
