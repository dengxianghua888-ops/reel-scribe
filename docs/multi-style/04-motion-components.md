# 04 动效组件体系：效果优先，原子化，按需求选实现方式

完整目录：[catalog/components.md](catalog/components.md)（126 个组件，按 16 类列出首选引擎、备选引擎、可编辑属性与被引用次数），引擎说明在同一文件开头。机器可读：[catalog/facets.json](catalog/facets.json) 的 `components` 与 `engines`。

## 一、三条原则

1. **效果第一。** 先写清楚这个效果在画面上必须达到什么（例如“说到这个数时，表格只亮这一行，其余行降为暗灰，0.12 秒内到位”），再选实现。效果不达标时换引擎，而不是降低效果标准。
2. **组件是效果合同，引擎是实现。** 一个组件只定义属性、时间、版位、检查项；它可以有多个引擎实现（首选与备选），都要通过同一套检查。风格包引用组件，不引用引擎。
3. **可编辑优先于渲染件，但不以牺牲效果为代价。** 剪辑 Agent 原生组件能达到同等效果时优先用原生实例，用户可直接在属性面板里改；达不到时用渲染件（带 alpha 的视频或序列），属性仍保存在 Work 里，改值后重渲染。

## 二、组件的三层

| 层 | 是什么 | 例子 |
|---|---|---|
| 效果原子 | 最小的可感知效果，带可测指标 | 逐词升起、遮罩揭示、描边书写、数字滚动、荧光划线、推近、墨晕转场 |
| 组件 | 效果原子＋属性表＋时间模型＋版位约束＋检查项 | `data-spec-table` 规格表逐行点亮、`card-lower-third` 姓名条、`cap-pill-highlight` 胶囊底高亮 |
| 组件实例 | 组件在某个作品、某个时刻的一次使用，保存覆盖值 | 第二张规格表把“500 g”改为“0.5 kg”，第一张不变 |

## 四、14 种实现方式与选择规则

| 需求特征 | 选用 | 理由 |
|---|---|---|
| 字随着说话出现，要和字幕烧录同一条链 | ASS/libass | 最快、确定，`caption-burn` 已在用 |
| 中文精排、卡片版式、数据图、界面与社媒卡 | HTML/CSS/JS 逐帧渲染（固定无头浏览器版本） | 排版和设计 token 能力最强；参照 HyperFrames 的可 seek 时间协议 |
| 设计师已有 AE 动画、图标动画、手写笔顺 | Lottie（rlottie 或 lotio 逐帧导出） | 直接复用设计资产；只开放文本层、颜色、时间等有限属性 |
| 程序化讲解图、流程、代码动画 | Motion Canvas / Revideo | 生成器式时间控制，适合讲解节奏 |
| 公式推导 | Manim | 数学排版与变换最佳 |
| 转场、风格化、光效、背景 | WebGL/GLSL | 效果上限高，gl-transitions 可作着色器来源 |
| 真实 3D 文字、产品转台、空间卡片 | Three.js；要最高品质时 Blender | 真实空间感；Blender 慢，留给品牌类 |
| 推近、裁切、色键、马赛克、变速、调色等像素变换 | FFmpeg 或宿主 | 不需要新运行时；宿主可编辑性更好 |
| 需要知道人或物在哪里 | 视觉模型（SAM2 等）只出遮罩与轨迹，再交给上面的引擎画 | 分析与绘制分开，换模型不影响组件合同 |
| 真人转手绘、素描 | 风格迁移 | 实拍得不到的质感；跨帧稳定是主要检查项 |
| 用户需要在剪辑 Agent 里直接改 | 宿主原生组件 | 可编辑性最好；效果须通过同一套检查 |
| 画面里需要原本没有的东西 | 生成模型（经生成接口） | 片内修改需重生成，不能作事实证据 |

**打分选引擎。** 同一组件有多个候选实现时，按下式选首选，其余作备选：

```
引擎分 = 0.40·效果上限 + 0.20·宿主可编辑性 + 0.15·确定性与可复现 + 0.10·渲染成本 + 0.10·依赖与许可 + 0.05·中文排版
```

效果上限由该组件的黄金帧对照评定（见 §六），不是凭印象打分。许可为“仅非商业”的依赖得 0 分。

## 五、按场景的实现组合（由目录统计得出）

下表是 264 个风格包实际用到的引擎占比（一个包用到某引擎即计一次），反映不同场景的主要实现方式：

| 领域 | 包数 | 主要引擎占比 | 解读 |
|---|---|---|---|
| 真人口播与知识表达 | 52 | HTML 94%、ASS 87%、FFmpeg 17%、Lottie 13% | 以字幕与信息卡为主，HTML 与 ASS 两条链必须先做好 |
| 对话与多人 | 25 | ASS 96%、HTML 92%、FFmpeg 28%、Motion Canvas 16% | 说话人分色、姓名条、关系图解 |
| 商品与商业 | 57 | ASS 88%、HTML 88%、FFmpeg 23%、Lottie 14%、GLSL 9% | 数据卡、价格条件、放大镜；品牌类需要 GLSL 与 3D |
| 生活与纪实 | 48 | ASS 88%、HTML 75%、FFmpeg 31%、GLSL 15%、Lottie 15% | 质感、漏光、手写，FFmpeg 与 GLSL 比重上升 |
| 娱乐与叙事后期 | 39 | ASS 87%、HTML 74%、FFmpeg 51%、GLSL 18%、宿主 10% | 定格、变速、转场最多 |
| 版本与适配 | 24 | ASS 92%、HTML 62%、视觉模型 12% | 竖屏重构依赖主体跟随 |
| 图文与生成补足 | 19 | ASS 95%、FFmpeg 32%、Lottie 21%、视觉模型 11% | 静图运镜、2.5D、手绘图解 |

结论：首批只做 ASS、HTML、FFmpeg 三个适配器，就能覆盖绝大多数皮肤包；GLSL 与 Lottie 是第二批；视觉模型、3D、风格迁移、生成随机制包立项。

## 六、统一组件合同

每个组件目录包含：

```
facets/components/<id>/
  component.json          # 属性表、时间模型、版位、tokens、检查项、引擎绑定列表
  engines/html/index.html # 各引擎实现，可多个
  engines/ass/template.ass
  golden/<engine>/t0.png t50.png t100.png   # 黄金帧：开始、中点、结束
  parity.json             # 各引擎与首选实现的对照结果
  NOTICE.md               # 字体、素材与参照来源的许可
```

`component.json` 在 [facets.schema.json](schemas/facets.schema.json) 的 `component` 定义上扩展 `engine_bindings`：

```json
"engine_bindings": [
  {"engine": "html", "template": "engines/html/index.html", "engine_version": "chromium@pinned", "role": "primary"},
  {"engine": "host", "host_component": "spec-table", "role": "editable", "parity": "layout-equivalent"},
  {"engine": "ass",  "template": "engines/ass/template.ass", "role": "fallback", "parity": "degraded:no-row-dimming"}
]
```

**输出格式**：带 alpha 的 ProRes 4444、PNG 序列或 WebM（VP9 alpha），或宿主原生实例。每次渲染出回执：组件与模板版本、引擎版本、属性摘要、tokens 摘要、帧数、时长、alpha 检查结果。

**属性等价测试**：同一组属性分别用首选与备选实现渲染，比对 t0/t50/t100 三帧。版式等价的实现要求结构相似度不低于 0.90，且文字、数值逐字一致；达不到的实现只能标为降级，并在 `parity` 中写明缺了什么（如“无行压暗”）。

## 七、组件质量检查

| 检查 | 测量 | 门槛 |
|---|---|---|
| 可读 | 字号不低于设计系统该级最小值（按 1080 短边）；文字与背景对比度 | 对比度不低于 4.5:1 |
| 遮挡 | 组件与人脸框交并比；文字穿人时内容词被遮比例 | 人脸 IoU 为 0；穿人时目标覆盖 30–55%，任一内容词不超过 80%（参照 HyperFrames 的实测经验） |
| 时机 | 组件出现与锚点词起点之差 | −300 ms 至 +200 ms；退出不早于最短停留 |
| 运动 | 入场与退场使用设计系统的缓动；无抖动；不超过最长停留 | 设计系统声明值 |
| 中文正确 | 无缺字方框、避头尾、数字与单位同行、每行字数 | 设计系统 `cjk` 规则 |
| alpha 边缘 | 叠到黑、白、灰三种底上无黑边与描边断裂 | 人工抽检加像素统计 |
| 安全区 | 9:16 画布避开平台界面区域 | 首版取上 108、下 320、左 60、右 120 像素（第三方实测建议，国内平台须真机校准） |
| 确定性 | 同输入重渲染 | 帧哈希一致（GLSL 与模型类允许声明容差） |
