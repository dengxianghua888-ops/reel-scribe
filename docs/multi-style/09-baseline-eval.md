# 09 基线定义、评测集与优质样本：把“不平庸”做成硬门槛

风格包要上架，必须在盲评中**稳定胜过定义好的默认基线**。本章先定义四级基线，再定义评测集、优质样本库、评审协议和放行门槛。

## 一、四级基线

| 级别 | 名称 | 作用 | 是否门槛 |
|---|---|---|---|
| B0 | 行业技术基线 | 字幕、响度、安全区、音画同步、色彩、编码的通行规范；任何产物都必须满足 | 是，一票否决 |
| B1 | 默认基线（规则基线） | 可复现的“什么风格都不加”的版本；风格包必须胜过它 | **是，硬门槛** |
| B2 | 开源最佳基线 | 同素材用公开开源工具能得到的最好结果 | 否，用于对标 |
| B3 | 人工专业参照 | 职业剪辑师按同一 brief 剪的版本 | 否，追踪差距 |

### B0 行业技术基线

| 项目 | 规则 | 依据 |
|---|---|---|
| 字幕阅读速度 | 简体中文成人内容不超过 9 字/秒，儿童内容不超过 7 字/秒 | [Netflix 简体中文字幕规范](https://backlothelp.netflix.com/hc/en-us/articles/215986007-Chinese-Simplified-Timed-Text-Style-Guide) |
| 字幕行数与字数 | 每屏最多 2 行；16:9 每行不超过 16 字，9:16 每行不超过 12 字 | Netflix 常见问答对简体中文列出 16 与 23 两个数值，取严格值；竖屏为本方案自定 |
| 字幕时长 | 单条不短于 5/6 秒、不长于 7 秒；相邻两条至少间隔 2 帧 | [Netflix 字幕时间规则](https://backlothelp.netflix.com/hc/en-us/articles/360051554394-Timed-Text-Style-Guide-Subtitle-Timing-Guidelines) |
| 响度 | 流媒体交付默认 −14 LUFS 综合响度，真峰值不高于 −1 dBTP；广播交付按 EBU R128 的 −23 LUFS | YouTube、Spotify 的归一化目标多方记载为 −14 LUFS；短视频平台未见官方公开目标，须真机核对 |
| 竖屏安全区 | 1080×1920 画布内，关键文字与人脸避开上 108、下 320、左 60、右 120 像素 | 第三方对 TikTok 界面的实测建议；国内平台须真机校准 |
| 横屏安全框 | 动作安全 93%、字幕安全 90% | SMPTE ST 2046-1 |
| 音画同步 | 声音超前不超过 45 ms、滞后不超过 125 ms（可察觉阈）；绝对上限超前 90 ms、滞后 185 ms | ITU-R BT.1359 |
| 色彩与编码 | BT.709 SDR；帧率与源一致且恒定；无丢帧；商品画面色差中位数 ΔE2000 不超过 2（对照色卡） | 影述现有色彩合同；色差门槛为本方案自定 |
| 保护项 | 受保护的词、数值单位、否定、引用归属、证据镜头零改动 | 影述[证据合同](../../contracts/evidence-contract.md) |

### B1 默认基线：精确定义

B1 有两种，分别对照“包装”与“剪辑”两层：

**B1-P 包装基线**（对照风格包）：与被测风格包**完全相同的剪辑结果**（同一份词级计划与时间线），只把包装换成：

| 项 | 取值 |
|---|---|
| 字幕 | `cap-baseline-plain`：思源黑体 Medium（OFL），白字，2 px 黑描边，无阴影；16:9 为 48 px，9:16 为 56 px（1080 短边）；整句分组；位于安全区内底部居中；遵守 B0 字幕规则 |
| 组件 | 无 |
| 影调 | `look-neutral`：只做曝光与白平衡技术校正 |
| 声音 | 无音乐、无音效；原声归一到 −14 LUFS |
| 转场 | 硬切 |

这样对照只差包装一项：胜出说明风格在增加信息或感受，而不是在制造噪声。

**B1-E 剪辑基线**（对照方法卡与整包）：按场景用固定规则剪，再加 B1-P 包装：

| 场景族 | 规则剪法 | 工具 |
|---|---|---|
| 口播、访谈、课程、会议 | 按静音阈值去掉停顿与空白，不做语义选择 | auto-editor（公有领域），固定版本与参数 |
| 商品、直播切片 | 按人工标注的商品区间直切，顺序不变 | `timeline-render` |
| Vlog、旅行、纪录、活动 | 按 PySceneDetect 切点取每镜前 N 秒，按文件时间排序 | PySceneDetect（BSD-3-Clause） |
| 体育、游戏、综艺 | 取音频能量与画面变化最高的若干窗口 | `media-signal-scan` |
| 音乐混剪 | 按 4 拍等长切换镜头 | 拍点或固定 BPM |
| 版本与适配 | 中心裁切到目标画幅，按时长截断 | `video-reframe` |

所有参数和工具版本写入基线定义文件，基线视频可由任何人复跑出来。

### B2 开源最佳基线

| 场景族 | 组合 | 许可 |
|---|---|---|
| 口播精剪 | FunClip（转写＋LLM 选段）＋ ai-video-captions 的经典逐词样式 | MIT、MIT |
| 影视与短剧解说 | NarratoAI | MIT |
| 长视频拆条 | AI-Youtube-Shorts-Generator | MIT |
| 本地化 | VideoLingo | Apache-2.0 |
| 图文成片 | MoneyPrinterTurbo | MIT |

B2 用来回答“比开源方案好多少”，不作上架门槛。

### B3 人工专业参照

同一素材、同一 brief，由至少 2 位有 5 年以上后期经验的剪辑师各自独立完成（做法参照 Auto-Director 论文以专业剪辑师独立作品作人类参照）。B3 只追踪差距：目标是风格包对 B3 的偏好率达到 40% 以上（“接近人工”）。

## 二、评测集

### 构成（首版）

| 集合 | 条数 | 内容 | 来源 |
|---|---|---|---|
| 口播与知识 | 40 | 知识、观点、测评、教学、经历、资讯、财经、正式讲话各 5 条，1–15 分钟 | 自有或授权录制 |
| 对话与多人 | 12 | 访谈、播客、课程、会议各 3 条 | 自有或授权录制 |
| 商品 | 20 | 实拍种草、直播回放、开箱、品牌各 5 组；含 4 组外形相近的易混 SKU | 商家授权素材 |
| 生活与纪实 | 16 | Vlog、旅行、美食、健身、家庭、纪录、调查、活动各 2 条 | 自有或授权 |
| 娱乐后期 | 12 | 影视解说、短剧切条、综艺、游戏、体育、音乐各 2 条 | 已授权片源；开放影片（Netflix Open Content《Sparks》CC BY 4.0、Blender 开放电影 CC BY）用于解说与切条测试 |
| 版本与生成 | 10 | 拆条、本地化、精华版、参考复刻、图文、讲解动画、数字人 | 由上面的成片派生 |

### 每条素材的标注

| 标注 | 内容 | 参照 |
|---|---|---|
| 保护项 | 不得删改的词、数值、否定、证据镜头 | 影述证据合同 |
| 信号真值 | 数值、规格对、步骤、引语、转折、章节的人工标注（带词 ID） | 用于 `content-signal-extract` 召回与精确 |
| 可接受风格包 | 2 名标注者各自给出“可以接受的包”集合，分歧单列 | 用于路由 Top-3 可接受率 |
| 镜头属性与剪切类型 | 景别、角度、运动、剪切类型 | AVE 的 8 项、MovieCuts 的 10 类、ShotBench 的 8 维 |
| 内容问答 | 3–5 道看完能回答的事实题 | 用于“理解不退化” |
| B3 人工版本 | 见上 | — |

数据集只存清单（文件指纹、来源、授权、标注），原始媒体留在本地资料库，沿用影述“历史证据不完整随包”的做法。公开数据集（AVE、MovieCuts、VEU-Bench、CutCraft、DramaAD）只借标注口径和出题方式，不打包分发。

## 三、优质样本库

优质样本是“这类内容做得好的样子”的参照，用来校准节奏与密度、提炼新风格包、给评审一个共同的参照系。

**入选标准**（同时满足）：

1. 来自该场景公认的头部创作者、平台精选、行业奖项或品牌官方作品；
2. 风格能用一句话描述，且至少一个签名手法可以指认；
3. 至少 2 名剪辑或设计评审独立认可；
4. 公开可访问，记录链接与存证日期，不下载分发。

**样本卡**（Schema：[exemplar-card.schema.json](schemas/exemplar-card.schema.json)）记录：

| 字段 | 内容 | 测量方式 |
|---|---|---|
| 身份 | 链接、平台、发布日期、存证日期、时长、画幅、场景 | 人工 |
| 节奏指纹 | 平均镜长、每分钟切点数、最长与最短镜头、开头 3 秒是否给出主张或结果 | PySceneDetect |
| 字幕指纹 | 字/秒、每屏字数、逐词或整句、强调词比例 | 转写与画面 OCR |
| 包装指纹 | 每分钟图形事件数、同屏最多组件数、强调色面积占比 | 人工抽帧＋像素统计 |
| 声音指纹 | 综合响度、音乐时长占比、音效每分钟次数 | FFmpeg ebur128 |
| 镜头语言 | 景别分布、剪切类型分布 | AVE / MovieCuts / ShotBench 口径 |
| 风格描述 | 对应的设计系统族、字幕样式、影调、签名手法 | 本库刻面词表 |
| 借鉴与不借鉴 | 可借的机制；不能借的身份元素（人脸、声音、商标、片头、配色组合） | 人工 |

**数量**：第一期每个 P0 场景收集 10 条，其余场景各 5 条。

**用途**：

- 节奏刻面的参数区间（例如某场景优质样本的平均镜长分布）从样本卡统计得出，替代凭经验填写；
- 新风格包的灵感来源，但必须改写为机制描述，不复刻身份元素；
- 评审培训：评审先看同场景 3 条样本卡，再开始盲评。

## 四、评审协议

| 项 | 规定 |
|---|---|
| 评审池 | 目标观众至少 30 人（按平台人群抽样）；创作者或剪辑师至少 5 人 |
| 盲评形式 | 成对比较，左右随机，去掉一切标识；两版响度一致；只给本场景的观众任务说明 |
| 问题 | ① 更愿意看完或发布哪一版；② 内容问答；③ 用一句话描述这一版的视觉特点；④ 标出遮挡、错重点、太花、太素的时间点 |
| 一致性 | 专家组 Krippendorff α 不低于 0.6，否则修订评审指引后重评 |
| 排序 | 同场景多包用 Bradley–Terry 模型排序 |
| 自动预筛 | 风格一致性检查、`taste-review` 模型评审、VMAF；生成插入镜另用 VideoScore2。预筛只排除明显失败的候选，不替代盲评；DOVER 为非商业许可，只用于研究阶段 |

## 五、放行门槛

| 门 | 内容 | 门槛 |
|---|---|---|
| G0 技术 | B0 全部通过 | 一票否决 |
| G1 保真 | 保护项零违例；内容问答正确率不低于 B1-P 减 5 个百分点 | 一票否决 |
| **G2 胜基线** | 对 B1-P 的成对偏好：至少 100 次判断（如 20 条 × 5 人），胜率不低于 60%，且 Wilson 95% 置信区间下界高于 50%；“无差别”各计半票 | **硬门槛** |
| G3 识别度 | 签名手法识别率不低于 0.6；同场景两包的描述匹配正确率不低于 0.7 | `limited-trial` 起要求 |
| G4 对标 | 对 B2 的胜率、对 B3 的偏好率 | 只记录，第三期起设目标 |

状态升级：`catalog-draft` → `compiled`（编译器在合成样例上通过）→ `previewed`（1 条真实素材出过风格帧与样段）→ `limited-trial`（3 条以上真实素材，过 G0–G3）→ `validated`（10 条以上，过 G0–G3，且局部改成功率不低于 95%）。货架只展示 `limited-trial` 以上的包。

## 六、反平庸的五个机制

| 机制 | 要求 | 检查 |
|---|---|---|
| 签名手法 | 每个包 1 个，成片中至少出现 3 次，与内容信号绑定，能一句话描述 | 计次＋G3 |
| 克制规则 | 每个包至少 2 条“不做什么” | 可测的自动检查，其余进模型评审 |
| 强度曲线 | 包装强度随内容起伏，每 10 秒窗口事件数的峰谷比不低于 2 | 自动 |
| 视觉层级 | 任一时刻只有一个第一视觉落点 | 同屏组件数与强调色面积 |
| 俗套清单 | 命中且无正当理由时路由扣分、编译告警 | 编译器与模型评审 |

剪辑侧俗套清单（首版）：

| ID | 俗套 | 何时可以用 |
|---|---|---|
| `every-line-popup` | 每句话都弹花字 | 综艺式快问快答，且只弹关键词 |
| `random-sfx` | 无触发的音效点缀 | 音效有明确触发（扣合、点亮、翻页） |
| `whoosh-every-cut` | 每一刀配转场音 | 章节切换，全片不超过章节数 |
| `constant-punch-in` | 全程推近抖动 | 只在主张或笑点处，每分钟不超过 2 次 |
| `rainbow-keywords` | 每屏多色高亮 | 设计系统只有一个强调色时不会发生 |
| `emoji-sprinkle` | 随机贴表情 | 说话人本人的风格，且系列一致 |
| `stock-broll-cover` | 用无关空镜盖住讲者 | B-roll 证明或解释正在说的内容 |
| `bgm-wall` | 音乐从头铺满 | 音乐片；口播只在开头与转场进入 |
| `zoom-every-number` | 每个数字都放大 | 只放大与结论直接相关的数字 |
| `glitch-transition` | 无动机故障转场 | 内容关于故障、黑客或时间跳跃 |
| `template-intro` | 通用片头动画 | 系列品牌片头，不超过 2 秒 |
| `fake-urgency` | 倒计时、假稀缺 | 不可用；真实期限用文字说明 |
| `beauty-blanket` | 全片一刀切美颜 | 用户明确要求，且保护肤色色相 |
| `subtitle-everything-giant` | 全程巨大字幕 | 无声观看场景且画面信息少 |

## 七、指标汇总

| 层 | 指标 | 定义 |
|---|---|---|
| 路由 | Top-3 可接受率 | 三个方向与标注“可接受包”集合有交集的比例 |
| 路由 | 方向差异度 | 三个方向两两相似度的平均值，越低越好，目标低于 0.6 |
| 编译 | 确定性 | 同输入重复编译字节一致 |
| 一致性 | 局部改成功率 | “只改第二处”类修改不影响非目标对象的比例 |
| 审美 | 胜基线率、签名识别率、包间可区分率 | 见 G2、G3 |
| 结果 | 首选采纳率、返工分钟、系列复用率 | 用户侧统计 |
